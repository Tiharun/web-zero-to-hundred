# M3 홈 1행(퀘스트 카드·레벨 패널) 구현 계획서

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 홈 맨 위의 소개 문구·진도율 카드를 1행 "퀘스트 카드(상태 5종) + 레벨 패널(LV 배지, XP 막대, 통계 3행)"로 바꾼다.

**Architecture:** 계산은 순수 함수로 둔다. XP·레벨은 새 `level.js`, 퀘스트 상태(어느 Day, 어떤 문구)는 `progress.js`의 `questState`가 `prog`에서 매번 계산한다(저장하지 않는다, 스펙 6장 4). 화면은 `views/quest.js`(퀘스트 카드)와 `views/hud.js`(레벨 패널)가 만들고 `home.js`는 조립만 한다. 움직임은 `motion.js`의 `tilt`(이미 있음)와 새 `xpFill`을 쓴다.

**Tech Stack:** 바닐라 JS(ESM), CSS 컨테이너 쿼리, Web Animations API(`clip-path`), `node:test`, 전역 Playwright 1.63.0, pixelmatch 8.0.0.

**Spec:** `docs/superpowers/specs/2026-11-12-unified-roadmap-design.md` 11.2 M3, 5장(파일 역할), 6장(데이터 흐름), 7장(빈 상태). 모양·값은 `DESIGN.md` Layout(홈 순서, 컨테이너 쿼리), Components(Cards "퀘스트 카드"·"레벨 패널", HUD, Icons, Motion). 구성·상태는 `design-system/web-zero-to-hundred/pages/home.md` 3~5절. 마크업·CSS·문구의 출발점은 승인 시안 `design-system/web-zero-to-hundred/prototype/src/`(`view.mjs` `questCard`·`facts`·`bigNum`·`encouragement`·`levelPanel`, `style.css` 384~455행, `app.js` 391~410행·505~507행). 이 폴더는 로컬 전용이다.

**M3 완료 기준(스펙 11.2):** ① 큰 Day 번호와 "이어서 하기"가 첫 화면에 보인다 ② Day를 완료하고 돌아오면 XP 숫자와 막대가 늘어 있다 ③ 1280px에서 2/3 + 1/3으로 나뉜다. M1에서 넘긴 일: 퀘스트 카드 `tilt(el, 2)`, 상태별 주 버튼은 자동으로 Magnetic(`main.js`의 `magneticIn`이 이미 `.btn-primary`를 따라간다).

## Global Constraints

- 색·글꼴·크기·간격·모서리·턱·모션 값은 `DESIGN.md` 토큰(`var(--…)`)으로만 쓴다. 토큰 파일 밖에 색 값(`#hex`, `rgb(`, `hsl(`)과 `font-family`를 쓰지 않는다. 숫자를 직접 쓰는 예외는 DESIGN.md가 숫자로 정한 것뿐이다: LV 숫자 `32px`, XP 막대 높이 `24px`·칸 사이 `3px`·`10%` 무늬, LV 배지 최소 폭 `76px`, Tilt `perspective(1000px)`, XP 채움 `600`·`240`(ms).
- The One Pink Rule: 홈의 분홍 면은 퀘스트 카드의 주 버튼 하나다. XP 막대는 `xp`(초록), LV 배지는 `paper` 바탕 + `edge` 테두리·턱이다.
- One Big Number: 큰 숫자(`--text-display` 80px)는 퀘스트 카드의 Day 번호 하나뿐이다.
- The Two Icon Rule: 퀘스트·트로피·코인·별·월드 엠블럼은 도트 아이콘(`px(…)`), 모두 `aria-hidden`이고 뜻은 옆 글자가 맡는다.
- Label-Only Pixel: Galmuri(`--font-label`)는 Label("오늘의 퀘스트", "레벨", "Day", "LV", XP 글자)에만 쓴다. 숫자와 본문은 Wanted Sans.
- Real Progress·지어낸 수치 금지: 모든 숫자는 `prog`와 `cur`에서 계산한다. 연속 학습일·순위·후기 없음. 게임 어휘는 라벨에만, Day 제목·요약 글은 그대로.
- The Fluid Rule: 320px부터 가로 스크롤 0. 바뀌는 지점은 DESIGN.md 표의 값만 쓴다: `.main` `(min-width: 42rem)` 1행 2단, `(max-width: 41.99rem)` 통계 가로 3칸, 퀘스트 카드 `(min-width: 32rem)` 번호·내용 2단, `(max-width: 40rem)` 카드 안쪽 여백 축소, `(hover: hover) and (pointer: fine)` Tilt, `(prefers-reduced-motion: reduce)`.
- 동작 줄이기: Tilt·XP 채움·Stagger를 건너뛰고 최종 상태로 보인다. 정보와 기능은 그대로다.
- 화면 함수의 입력은 `ctx`뿐이다. 두 화면이 쓸 모양(월드 엠블럼 색, 숫자 글꼴 `.num`)은 공용(`components.css`, `icons.js`)에 둔다.
- 작은 문제는 미루지 않는다(CLAUDE.md 7장): 찾은 즉시 재현 테스트 → 수정 → 전체 테스트. 다른 마일스톤 화면이 있어야만 되는 일만 로드맵 11장에 `(M3에서 넘김: …)`.
- 커밋·push는 사용자가 요청할 때만, Task 경로만 고른다. 저장소 파일에 모델 식별자·개인정보를 쓰지 않는다. 기준 이미지는 사용자 승인 뒤에만 갱신한다.

## 범위 판정 (실행 전에 정한 것)

- **퀘스트의 Day = `continueTarget(cur, prog)`.** 시안은 `lastDay`가 미완료면 그것을 먼저 고르지만, 앱의 `lastDay`는 Day 완료 때만 바뀌어(`completeDay`) 늘 완료된 Day다. 사이드바 오늘 칸(분홍 네모)과 같은 Day여야 하므로 같은 함수를 쓴다. `lastDay`는 "월드 클리어"와 "복습 링크" 판정에만 쓴다.
- **상태 5종과 우선순위:** 모두 완료(`done`) > 준비 중(`pending`, 대상 Day의 `ready === false`) > 월드 클리어(`clear`) > 처음(`start`, 완료 0개) > 공부 중(`continue`). 시안 `model()`의 순서와 같다. 저장 불가 알림은 셸 배너(이미 있음)와 `ctx.takeNotice()` 한 줄이 맡고 퀘스트 상태가 아니다.
- **월드 클리어 판정:** `lastDay`가 완료된 Day이고, 그 프로젝트가 모두 완료이고, 퀘스트 Day가 다른 프로젝트에 있고, 그 프로젝트에 완료가 0개일 때. `lastDay`가 없으면(옛 백업) 클리어로 보지 않고 `continue`다.
- **졸업 로드맵:** 지금 교재와 픽스처에는 `roadmap` 페이지가 없다(C33에서 생긴다). 있고 열려 있으면 주 버튼 "<제목> 보기", 없으면 주 버튼 없이 문장만 둔다.
- **진도율(%) 카드와 소개 문구는 없앤다.** home.md 3절 "뺀 것"과 레벨 패널이 대신한다. 원 설계서 4장의 "전체 진도(완료 Day 수 / 전체 Day 수)"는 레벨 패널 통계 "완료한 Day n / 전체"가 맡는다(문서 우선순위 2: 홈 구성은 home.md). `percent()`는 격려 문구가 계속 쓴다.
- **화면 h1:** 소개 영역의 h1(교재 제목)이 사라지므로 `.home` 맨 앞에 `<h1 class="sr-only">홈</h1>`(시안 template.html과 같다). 교재 제목은 상단 바 브랜드에 이미 있다.
- **학습 경로·부록 구역은 M4까지 그대로 둔다.** 월드맵·다른 월드·막혔을 때가 대신하는 것은 M4다. 이 두 구역의 기준 이미지는 1행이 바뀌어 위치만 달라진다.
- **사실 목록 클래스 이름은 `.quest-facts`.** 시안의 `.facts`는 월드 페이지(`project.js`)가 이미 쓰는 이름이라 겹친다.
- **XP 채움 "세션에 한 번"은 키 `xp`.** 홈 Stagger 키 `home`과 따로 센다. Day를 완료하고 돌아오면 늘어난 최종 값이 바로 보인다(완료 기준 ②).
- **넘기는 일:** 퀘스트 카드 hover·포커스 때 월드맵 오늘 칸 떠오름·말 점프 연결은 지도가 생기는 M4로, 월드 클리어 축하 조각은 M11(이미 그 행에 있음)로 넘긴다. Task 4에서 M4 행에 적는다.
- **DESIGN.md는 고치지 않는다.** 필요한 값이 모두 있다. 엠블럼 색(DESIGN.md Icons 표 "월드 엠블럼: ink / coin / coin-hi")은 `components.css`의 도트 색 배정에 한 줄 더한다.
