# M4 홈 월드맵·다른 월드·막혔을 때 구현 계획서

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 홈 1행 아래의 "학습 경로"·"부록"을 월드맵(뱀 배치 3종, 칸 상태 5종, 경로선, 범례, 툴팁) → 다른 월드(캐러셀·격자) → 막혔을 때로 바꾸고, 홈 모션(경로 그리기, 말 점프, 퀘스트 카드 연결, 축하 조각, 월드 카드 Tilt·Shake·Reveal)을 붙인다.

**Architecture:** 지도 좌표·경로·화살표 계산은 DOM 없는 새 `trail.js`(순수 함수, 단위 테스트). 칸 상태는 사이드바와 같은 `navDayState`를 그대로 쓴다. 화면은 `views/worldmap.js`(지도 카드), `views/worlds.js`(다른 월드 카드와 캐러셀), `views/helprow.js`(막혔을 때)가 만들고 `home.js`는 조립과 모션 연결만 한다. 새 모션은 `motion.js`에 함수로 더한다.

**Tech Stack:** 바닐라 JS(ESM), SVG(`vector-effect: non-scaling-stroke`), CSS 컨테이너 쿼리·Scroll Snap·subgrid, Web Animations API, IntersectionObserver, `node:test`, 전역 Playwright 1.63.0, pixelmatch 8.0.0.

**Spec:** `docs/superpowers/specs/2026-11-12-unified-roadmap-design.md` 11.2 M4, 5장(`trail.js`·`views/worldmap.js`), 6장 4(지도 상태는 저장하지 않는다), 7장(빈 상태), 8장(시각 품질 절차). 모양·값은 `DESIGN.md` Layout(홈 순서, 컨테이너 쿼리, 월드맵 배치, 다른 월드), Elevation(바닥 턱 목록, z-index), Shapes(점선), Components(Cards "월드 카드"·"잠긴 월드 카드"·"막혔을 때 칸", Board Tiles, Icons 도트 색 배정, Tooltip, Chips, Motion, Accessibility). 구성·상태는 `design-system/web-zero-to-hundred/pages/home.md` 3~6절. 마크업·CSS·문구의 출발점은 승인 시안 `design-system/web-zero-to-hundred/prototype/src/`(`view.mjs` 351~518행 `LAYOUTS`·`geometry`·`pathD`·`worldMap`·`legend`·`worldCard`·`helpRow`, `style.css` 457~642행, `app.js` 338~386행·438~450행·463~531행, `build-home.mjs` 19~63행). 이 폴더는 로컬 전용이다.

**M4 완료 기준(스펙 11.2):** ① 완료 칸이 초록이고 오늘 칸 위에 말이 있다 ② 잠긴 월드를 누르면 흔들리고 이유가 뜬다 ③ 승인 시안과 3폭에서 일치한다. 넘겨받은 일: (M1) 월드 카드 `tilt(el, 4)`, 잠긴 월드 카드 `shake()` + `showToast()`, 월드 카드 Reveal, 학습 경로의 잠긴 카드 Shake를 월드 카드로 옮김. (M3) 퀘스트 카드 hover·포커스 때 오늘 칸 4px 떠오름과 말 계속 점프, `home-first`·`home-clear` 기준 이미지 재승인.

## 범위 판정 (실행 전에 정한 것)

- **지도에 그리는 월드 = `questState(cur, prog).worldId`.** 시안 `mapWorld`와 같다(클리어·모두 완료면 끝낸 월드, 그 밖에는 퀘스트 Day의 월드). 오늘 칸은 `navDayState(cur, prog, d.id, state.dayId)`가 `'today'`인 칸 하나다 — 사이드바의 분홍 네모와 늘 같은 Day다.
- **칸 상태 우선순위는 사이드바와 같다(잠김 > 완료 > 오늘 > 준비 중 > 남음).** 그래서 "다음 Day 미작성"(퀘스트 `pending`)에서 그 Day 칸은 오늘(분홍, 말)이고, 그 뒤의 미작성 칸들이 점선이다. 스펙 7장 "칸은 점선"을 이렇게 읽는다: 승인 시안과 M2 사이드바가 이미 이 순서이고, 한 Day가 두 곳에서 다른 상태로 보이면 안 된다. 틀렸다면 비용은 칸 클래스 한 줄과 테스트 한 개.
- **초록 경로선은 1일차부터 이어서 끝낸 구간까지만(시안 `streak`).** 중간을 건너뛰고 끝낸 칸은 칸만 초록이다.
- **다른 월드 = 지도 월드를 뺀 모든 월드(메인 → 특별 순) + 졸업 카드.** 졸업 로드맵 페이지(`roadmap`)는 아직 없다(C33). 졸업 카드는 `getPage(cur, 'roadmap')`가 있으면 그 제목·`requires`·링크를 쓰고, 없으면 제목 "졸업 로드맵", 결과물 "다음 학습 경로와 4차 프로젝트 후보를 정리한 마지막 안내"(원 설계서 3.5절, 시안 `GRAD`), 여는 조건은 메인 트랙 마지막 월드다(코드에 `p3`를 쓰지 않는다). 열렸지만 페이지가 없으면 링크 없이 "아직 쓰는 중이에요."
- **잠긴 월드 카드의 클릭 레이어는 `<button>`.** 사이드바 잠긴 행(M2)과 같다. 누르면 카드 Shake + 토스트(`‘<월드>’ 월드는 <lockReason>`) + 발판 문장 강조(`.is-told`). 이동하지 않는다. 지금 `<a aria-disabled>` 학습 경로 카드와 그 CSS는 Task 3에서 지운다.
- **월드 카드 Reveal:** 카드마다 `reveal()`(화면에 들어올 때 한 번, 개편 설계서 "홈 월드 카드"). 다른 월드 구역 자체에는 `data-reveal`을 두지 않아 Stagger와 겹치지 않는다. Stagger 대상은 알림·퀘스트·레벨·월드맵·막혔을 때다.
- **막혔을 때 = 부록 중 `help`, `troubleshooting`, `glossary`, `start`를 이 순서로, 있는 것만.** 그림은 ladder, wrench, words, book. 그 밖의 부록(`secret`, 앞으로의 `roadmap`)은 홈에 두지 않는다(사이드바 "부록"에 있다).
- **막혔을 때 설명 한 줄은 `curriculum.json` 페이지의 새 선택 키 `meta`.** 생성 페이지의 `{n}`은 빌드가 실제 개수(용어 항목 수, 증상 항목 수)로 바꾼다. 문구는 시안 `build-home.mjs`의 것: help "막혔을 때 따라 할 순서", troubleshooting "증상 {n}가지와 해결 방법", glossary "용어 {n}개를 한 줄 정의로", start "교재 쓰는 법, 공부 원칙, 준비물". 시안의 "①~⑨ 단계 수"는 지금 `help.md`에 그런 줄이 없어(측정: 0개) 쓰지 않는다.
- **배포 Day = 제목에 "배포"가 들어간 Day**(DESIGN.md Board Tiles). 픽스처에 그런 Day가 없어 e2e 변형 교재의 `fs` 둘째 Day 제목을 "특별 둘째 Day 배포"로 바꾼다.
- **축하 조각은 M4에서 한다.** M3 계획서는 M11로 넘긴다고 적었지만 DESIGN.md Motion 표가 홈 모션(월드 클리어·모두 클리어의 큰 Day 번호)으로 정하고 스펙 M4가 "홈 모션"을 맡는다. M11 행의 축하는 Day 화면 보상 연출로 남는다.
- **시각 장면:** 지도가 첫 화면(높이 900) 아래에 있으므로 `home`·`home-first`·`home-clear`를 전체 페이지(`fullPage`)로 찍고, 모두 완료 장면 `home-done`(375·1280)을 더한다. 기준 이미지 40장.
- **`onceInSession`이 저장소 접근 예외에 죽는 결함을 고친다.** 지금은 기본 인자 `storage = globalThis.sessionStorage`가 `try` 밖에서 평가되어, 저장소가 막힌 브라우저(접근 자체가 `SecurityError`)에서 홈이 그려지지 않는다. Task 5에서 재현 테스트 → 수정.
- **DESIGN.md는 고치지 않는다.** 필요한 값이 모두 있다.

### Task 1: `trail.js` — 뱀 배치 좌표·경로·화살표

**Files:**

- Test: `tests/unit/trail.test.mjs`(새 파일)

**Interfaces:**
- Consumes: 없음(순수 함수, DOM 없음)
- Produces:
  - `LAYOUTS: { s: { cols: (n) => 5, rowH: 84 }, m: { cols: (n) => 10, rowH: 84 }, l: { cols: (n) => Math.min(15, Math.ceil(n / 2)), rowH: 88 } }`
  - `geometry(n: number, cols: number) → { rows: number, cols: number, pts: { r: number, c: number, x: number, y: number, vx: number, vy: number }[] }` — 짝수 줄 왼→오, 홀수 줄 오→왼. `x`·`y`는 % (`((c + 0.5) * 100) / cols`, `((r + 0.5) * 100) / rows` — 시안의 `((c + 0.5) / cols) * 100`은 `0.3 * 100 = 30.000000000000004` 같은 오차가 나서 곱셈을 먼저 한다), `vx`·`vy`는 viewBox 단위(칸 하나 = 100, `(c + 0.5) * 100`). `n === 0`이면 `{ rows: 0, cols, pts: [] }`.
  - `layouts(n: number) → { s: Geo, m: Geo, l: Geo }` — 세 배치를 한 번에.
  - `pathD(pts, upto: number) → string` — 0번부터 `upto`번 칸까지. 같은 줄은 `L`, 줄이 바뀌면 `C` 곡선(`bulge = a.c === 0 ? -42 : 42`, 시안 `pathD` 그대로). `upto < 1`이면 `''`.
  - `streakEnd(done: boolean[]) → number` — 앞에서부터 이어진 `true`의 마지막 번호, 없으면 −1.
  - `rowArrows(geo, streak: number) → { x: number, y: number, back: boolean, done: boolean }[]` — 줄마다 가운데 두 칸(`j = from + Math.floor((len - 2) / 2)`) 사이 하나. `x`·`y`는 %, `back`은 오→왼 줄, `done`은 `j + 1 <= streak`. 칸이 1개인 줄은 건너뛴다.
  - `tipSide(pt, cols: number) → 'start' | 'end'` — `pt.c < cols / 2`면 `'start'`.
