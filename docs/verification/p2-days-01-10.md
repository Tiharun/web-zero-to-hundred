## 개요와 달라진 점
- Day 1: `videos.json`은 `index.html`이 아니라 P1의 `contents.html`이 요청해요(레퍼런스 `contents.js`). 그래서 표의 첫 줄을 `contents.html`로 했어요.
- Day 2: 개요는 끝 상태에서 커밋 1개라고 했지만 과제 3이 두 번째 커밋을 만들어서 커밋 2개로 적었어요.
- Day 3: `npm run hello` 출력은 `> hello`가 아니라 `> ts-practice@1.0.0 hello`예요. 과제 1은 `npm pkg set scripts.hello=…` 대신 `package.json`을 직접 고치게 했어요(PowerShell 5.1 따옴표 처리 미확인).
- Day 4: `tsc --init` 결과를 통째로 간단한 파일로 바꾸게 했어요. `sourceMap`·`declaration`·`noUncheckedIndexedAccess`·`exactOptionalPropertyTypes`는 뺐어요(Vite 프로젝트 설정과 맞춤). 그래서 개요가 Day 5 막힘 후보로 든 `exactOptionalPropertyTypes` 오류는 나지 않고, `:::info`로만 설명해요.
- Day 5: 개요의 TS2339 대신 가장 흔한 `TS2820`(대문자)·`TS18047`을 실행해 확인했어요. `describeAvatar`로 "사진 없음" 출력, `?.`·`??`·`typeof` 예제를 더했어요.
- Day 6: 개요의 "1/1쪽" 출력은 `Math.ceil`이 Day 31에 처음 나오기 때문에 `1쪽, 한 쪽에 20명, 전체 3명`으로 바꿨어요. `filterBy<T>`는 단계에서 비제네릭 `filterStreamers`로 먼저 보이고 과제 1에서 일반화해요. 개요의 "Module has no exported member" 오류는 실제로 `TS2459`(declares locally)로 나와서 그 원문을 썼어요.
- Day 7: 개요의 HMR 설명을 실측에 맞게 고쳤어요(`main.ts`는 자동 새로고침). 개요의 방화벽 창은 loopback만 쓰는 경우 안 뜰 수 있어 "안 뜨는 컴퓨터도 많아요"로 적었어요. `package.json` 버전은 실행 당시 최신인 `vite ^8.3.6`(개요는 8.3.5)이에요.
- Day 8: 카드 제목은 섹션 제목(`h2`) 아래라서 `h3`로 만들었어요(레퍼런스의 `.card h2` CSS는 개요대로 넣어 두었고 Day 28에서 쓰여요). 개요의 "Network Offline" 실험은 새로 고침이 페이지 자체를 못 불러서 속도 제한(Slow 4G)과 **Block request URL**로 바꿨어요. `errorMessage`는 `noUnusedParameters` 때문에 `console.error(error)`로 `error`를 사용해요.
- Day 9: 개요의 `Program.cs(2,36)` 예시 대신 본문 코드에 맞는 `(8,25)`를 썼어요.
- Day 10: 개요의 단계는 시간표·`enum` 위주라서 `enum`이 파일 맨 아래에 있어야 하는 규칙(`CS8803`)을 단계에 넣고 이후 코드는 "열거형 주석 바로 위"에 삽입하게 했어요.
- 개요 문제(모두 보고서에 적음): 위 Day 1·2·3·5·6·7·8 항목.
