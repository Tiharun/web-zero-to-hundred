## 새로 확인한 사실 (측정, 이 PC, 2026-11-07)

- 한국어 Windows 11에서 `dotnet build`의 컴파일러 `error`·`warning` 문장이 한국어로 나와요(예: `error CS0029: 암시적으로 'string' 형식을 'int' 형식으로 변환할 수 없습니다.`, `warning CS8602: null 가능 참조에 대한 역참조입니다.`). 실행 중 예외(`Unhandled exception. …`)는 영어예요. 번호(`CS…`)는 같아요. 환경 변수 `DOTNET_CLI_UI_LANGUAGE=en`·`VSLANG=1033`로 영어 문장을 얻었어요.
- EF Core 10.0.14 + SQLite: `database update` 뒤 테이블은 `Streamers`, `__EFMigrationsHistory`, `__EFMigrationsLock`(+ `sqlite_sequence`)예요. `__EFMigrationsLock`은 적용하는 동안의 잠금용이에요.
- `dotnet new sln -n X`는 .NET SDK 10.0.402에서 `X.slnx`(Solution XML, 86바이트)를 만들어요.
- `.NET 10` C#에서 람다 매개변수 이름이 바깥 지역 변수와 같아도 오류가 아니에요(CS0136 안 남).
- `First(조건)`의 빈 결과 예외 문구는 `Sequence contains no matching element`예요(조건 없는 `First()`는 `no elements`).
