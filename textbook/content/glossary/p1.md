# P1 용어

### 인터넷
- 처음 등장: [P1 Day 1](#/day/p1-d01)

전 세계의 컴퓨터를 서로 연결한 거대한 통신망이에요. 메신저, 온라인 게임, 이메일, 웹이 모두 이 통신망 위에서 움직여요. 그래서 인터넷과 웹은 같은 말이 아니에요. 인터넷은 길이고, 웹은 그 길을 쓰는 서비스 가운데 하나예요.

### 웹
- 처음 등장: [P1 Day 1](#/day/p1-d01)

인터넷 위에서 웹페이지를 주고받고, 링크로 서로 이어 주는 서비스예요. 정식 이름은 World Wide Web(줄여서 WWW)이에요. 우리가 브라우저로 보는 모든 사이트가 웹에 속해요.

### 브라우저
- 처음 등장: [P1 Day 1](#/day/p1-d01)

웹페이지 파일을 받아 와서 사람이 볼 수 있는 화면으로 그려 주는 프로그램이에요. Windows 11에는 Microsoft Edge가 기본으로 들어 있고, Google Chrome도 많이 써요. 같은 HTML 파일이면 Edge와 Chrome에서 거의 똑같이 보여요.

### 서버
- 처음 등장: [P1 Day 1](#/day/p1-d01)

웹페이지 파일 같은 자료를 보관하고 있다가, 요청이 오면 보내 주는 컴퓨터(또는 프로그램)예요. 브라우저가 주소를 보내 "이 페이지 주세요"라고 요청하면, 서버가 그 주소에 맞는 파일을 돌려줘요. P1의 마지막에는 GitHub Pages라는 서버에 내 사이트를 올려요.

### URL
- 처음 등장: [P1 Day 1](#/day/p1-d01)

인터넷이나 내 컴퓨터에서 자료가 있는 위치를 가리키는 주소예요. `https://`로 시작하면 인터넷 너머의 서버에서, `file:///`로 시작하면 내 컴퓨터 안에서 파일을 가져와요. 브라우저 맨 위의 주소 표시줄에 보이는 글자가 URL이에요.

### 웹페이지
- 처음 등장: [P1 Day 1](#/day/p1-d01)

브라우저 화면 한 장에 보이는 문서 하나예요. 보통 HTML 파일 하나가 웹페이지 하나가 돼요. 예를 들어 `hello.html` 파일을 브라우저로 열면 웹페이지 한 장이 보여요.

### 웹사이트
- 처음 등장: [P1 Day 1](#/day/p1-d01)

서로 링크로 이어진 웹페이지 여러 장을 한 주소 아래에 모아 둔 묶음이에요. 홈, 소개, 영상 목록처럼 여러 페이지가 함께 하나의 사이트를 이뤄요. P1에서 만드는 "나의 크리에이터 홈페이지"가 웹사이트예요.

### HTML
- 처음 등장: [P1 Day 1](#/day/p1-d01)

웹페이지의 내용과 구조를 적는 언어예요. "여기는 큰 제목, 여기는 문단"처럼 꺾쇠 괄호 `< >`로 감싼 표시를 글자 사이에 넣어서 써요. HTML 파일은 글자로만 된 파일이라서 메모장 같은 텍스트 편집기로도 만들 수 있어요. 이름은 HyperText Markup Language의 머리글자예요.

### 코드
- 처음 등장: [P1 Day 1](#/day/p1-d01)

컴퓨터가 알아듣는 규칙(언어)에 맞춰 쓴 글이에요. HTML로 쓴 웹페이지 내용이 대표적인 코드이고, 앞으로 배울 여러 언어로 쓴 명령도 모두 코드예요. 코드는 보통 텍스트 편집기에 글자로 쓰고 파일로 저장해요.

### 텍스트 편집기
- 처음 등장: [P1 Day 1](#/day/p1-d01)

글꼴·색 같은 꾸밈 없이 글자만 쓰고 저장하는 프로그램이에요. Windows의 메모장이 대표적이고, Day 2에 설치하는 VS Code도 코드를 쓰기 좋게 만든 텍스트 편집기예요. 워드나 한글(HWP) 같은 문서 프로그램은 꾸밈 정보를 함께 저장하므로 HTML 파일을 만들 때 쓰지 않아요.

### 파일
- 처음 등장: [P1 Day 1](#/day/p1-d01)

컴퓨터에 이름을 붙여 저장한 자료 한 덩어리예요. 글, 사진, 음악, 프로그램이 모두 파일이에요. 파일 이름은 보통 `이름.확장자` 모양이에요.

### 폴더
- 처음 등장: [P1 Day 1](#/day/p1-d01)

파일과 다른 폴더를 담아 정리하는 상자예요. 폴더 안에 폴더를 넣을 수 있어서, `C:\dev` 안에 `hello` 폴더를 두는 식으로 층층이 정리해요. 디렉터리(directory)라고 부르기도 해요.

### 확장자
- 처음 등장: [P1 Day 1](#/day/p1-d01)

파일 이름에서 마지막 점(`.`) 뒤에 붙은 글자예요. `hello.html`의 확장자는 `html`이고, Windows는 확장자를 보고 이 파일을 어떤 앱으로 열지 정해요. 점이 여러 개면 마지막 점 뒤만 확장자라서, `hello.html.txt`는 웹페이지가 아니라 텍스트 문서(`.txt`)예요. Windows 메뉴에서는 "파일 확장명"이라고 불러요.

### 경로
- 처음 등장: [P1 Day 1](#/day/p1-d01)

파일이나 폴더가 어디에 있는지를 드라이브부터 차례로 적은 주소예요. `C:\dev\hello\hello.html`은 "C 드라이브 → dev 폴더 → hello 폴더 → hello.html 파일"이라는 뜻이에요. Windows는 폴더 사이를 `\`(역슬래시)로 구분하고, 한국어 키보드에서는 `₩` 키로 입력해요.

### UTF-8
- 처음 등장: [P1 Day 1](#/day/p1-d01)

글자를 컴퓨터가 저장하는 숫자로 바꾸는 방식(인코딩) 가운데, 한글·영어·이모지까지 전 세계 글자를 모두 담을 수 있는 표준이에요. 웹페이지는 UTF-8로 저장하고 HTML 안에도 `<meta charset="utf-8">`이라고 적어 두는 것이 기본이에요. 저장 방식과 적어 둔 방식이 서로 다르면 한글이 `�`처럼 깨져 보여요.
