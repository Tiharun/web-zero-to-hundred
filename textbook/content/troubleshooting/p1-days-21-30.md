3. `Enter` 뒤 주소 끝에 `#main`이 붙고 본문으로 가면 해결이에요.

### 파비콘이 안 바뀌어요
- 관련: [P1 Day 28](#/day/p1-d28)

**원인:** 브라우저가 아이콘을 오래 기억해요. 또는 경로가 틀렸어요(오버레이는 `../favicon.svg`).

**해결:** 새 탭으로 열거나 `Ctrl + F5`로 강력 새로 고침해요. 그래도 안 되면 `<link rel="icon" href="favicon.svg" type="image/svg+xml">`의 이름과 위치를 확인하고 시간을 두고 다시 열어요.

### Lighthouse 탭이 안 보여요
- 관련: [P1 Day 28](#/day/p1-d28)

**원인:** 개발자 도구 탭이 많으면 일부가 `»`(더 보기) 안에 숨어요. VS Code Live Preview 미리 보기 창에서는 개발자 도구가 열리지 않아요.

**해결:** `»` 안에서 **Lighthouse**를 찾고, Chrome에서 Live Preview 주소나 배포 주소를 열었는지 확인해요. 확장 프로그램 안내가 뜨면 시크릿 창(`Ctrl + Shift + N`)에서 다시 검사해요.

### 중단점을 걸었는데 멈추지 않거나, 계속 멈춰요
- 관련: [P1 Day 29](#/day/p1-d29)

**원인:** 멈추지 않는 경우: 그 줄이 이미 실행된 뒤에 걸었거나 다른 파일에 걸었어요. 계속 멈추는 경우: 해제하지 않은 중단점이 남아 있고, 멈춘 상태(**Paused in debugger**)에서 계속 실행을 안 눌렀어요.

**해결:**

1. 줄 번호를 걸고 `F5`로 새로 고치거나 그 코드가 실행되는 동작을 다시 해요.
2. 멈춘 채로 있으면 `F8`(계속 실행)을 눌러요.
3. Sources 오른쪽 **Breakpoints** 목록에서 체크를 끄거나 줄 번호를 다시 눌러 해제해요.

### README 가 GitHub 저장소 첫 화면에 안 보여요
- 관련: [P1 Day 29](#/day/p1-d29)

**원인:** 파일 이름이 `README.md`가 아니에요(`readme.txt`, `README.md.txt`). 또는 아직 푸시하지 않았어요.

**해결:**

1. 파일 탐색기 **보기 → 표시 → 파일 확장명**이 켜져 있는지 확인해요.
2. VS Code 탐색기에서 파일을 오른쪽 클릭 → **이름 바꾸기**로 `README.md`로 맞춰요.
3. 소스 제어 패널의 변경이 0개(푸시 완료)인지 확인하고 저장소를 새로 고침해요.

### Actions 에 빨간 ✕ 가 떠요
- 관련: [P1 Day 30](#/day/p1-d30)

**원인:** 배포 작업이 실패했어요. 일시적인 GitHub 문제이거나 파일 이름에 한글·공백·특수 문자가 있는 경우가 있어요.

**해결:**

1. 저장소 **Actions** → 실패한 실행을 클릭해 오류 내용을 읽어요.
2. 다시 실행 버튼(**Re-run jobs** 등, 이름은 버전에 따라 달라요)을 눌러요.
3. 계속 실패하면 파일 이름을 영어 소문자와 `-`로 바꿔 푸시해요.
4. 맨 위 실행이 초록 체크가 되면 해결이에요.
