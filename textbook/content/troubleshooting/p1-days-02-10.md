# P1 문제 해결 (Day 2~10)

### 내려받은 VS Code 설치 파일이 안 보여요
- 관련: [P1 Day 2](#/day/p1-d02)

**원인:** 브라우저가 파일을 `다운로드` 폴더에 저장하는데, 폴더가 OneDrive 안으로 옮겨져 있거나 내려받기가 끝나지 않았을 수 있어요. 그래서 파일 탐색기에서 찾으면 안 보일 때가 있어요.

**해결:**

1. 브라우저에서 `Ctrl + J`를 눌러 다운로드 목록을 열어요.
2. 목록 맨 위의 `VSCodeUserSetup-…` 항목이 "완료"인지 확인해요. 진행 중이면 끝날 때까지 기다려요.
3. 항목을 클릭하면 바로 실행돼요. 폴더 모양 아이콘(폴더에 표시)을 누르면 파일이 있는 폴더가 열려요.
4. 목록에 아무것도 없으면 `https://code.visualstudio.com/`에서 **Download for Windows** 버튼을 다시 눌러요.
5. 설치 마법사 첫 화면이 열리면 해결된 거예요.

### 파란 "Windows의 PC 보호" 창이나 "이 앱이 디바이스를 변경하도록 허용하시겠어요?" 창이 떠요
- 관련: [P1 Day 2](#/day/p1-d02)

**원인:** Windows는 내려받은 실행 파일을 처음 실행할 때 게시자를 확인하라고 알려 줘요. 처음 보는 프로그램이면 파란 경고(Microsoft Defender SmartScreen)가 뜨고, 설치할 때 사용자 계정 컨트롤(UAC) 창이 뜰 수도 있어요. 문구는 Windows 버전에 따라 조금 달라요.

**해결:**

1. 창에 쓰인 앱 이름이 Visual Studio Code인지, 게시자가 **Microsoft Corporation**인지 읽어요. 이 확인 없이 누르지 않는 습관이 중요해요.
2. 파란 경고 창이면 글자 **추가 정보**를 클릭하고, 새로 나타난 **실행** 버튼을 클릭해요. 게시자가 Microsoft가 아니거나 다른 사이트에서 받은 파일이면 실행하지 말고 지워요.
3. 사용자 계정 컨트롤 창이면 게시자를 확인하고 **예**를 클릭해요. User setup은 보통 이 창이 뜨지 않아요.
4. 설치 마법사의 사용권 계약 화면이 열리면 해결된 거예요.

### 설치할 때 관리자 암호를 물어요 (VSCodeSetup 파일을 받았어요)
- 관련: [P1 Day 2](#/day/p1-d02)

**원인:** 내려받은 파일 이름이 `VSCodeSetup-…`으로 시작하면 모든 사용자용으로 `Program Files`에 설치하는 System setup이에요. 이 방식은 관리자 권한이 필요해서 관리자 암호를 물어요. 이 교재는 관리자 권한이 필요 없는 User setup(`VSCodeUserSetup-…`)을 써요.

**해결:**

1. 암호를 묻는 창은 닫고, 설치 마법사도 취소해요.
2. 브라우저에서 `https://code.visualstudio.com/`을 열고 **Download for Windows** 버튼 대신 **Other platforms**(다른 플랫폼) 또는 다운로드 페이지의 Windows **User Installer**(x64)를 골라 내려받아요. 화면 이름은 버전에 따라 조금 달라요.
3. 내려받은 파일 이름이 `VSCodeUserSetup-`으로 시작하는지 확인하고 실행해요.
4. 관리자 암호 없이 사용권 계약 화면까지 가면 해결된 거예요.

### 한국어 팩을 설치했는데 메뉴가 영어예요
- 관련: [P1 Day 2](#/day/p1-d02)

**원인:** 한국어 팩은 설치한 뒤 VS Code를 다시 시작해야 적용돼요. 오른쪽 아래 알림의 **Change Language and Restart** 버튼을 놓쳤거나 알림이 사라졌을 수 있어요.

**해결:**

1. `Ctrl + Shift + P`를 눌러 명령 팔레트를 열어요.
2. `Configure Display Language`를 입력하고 `Enter`를 눌러요.
3. 언어 목록에서 `한국어`(`ko`)를 클릭해요. 목록에 없으면 확장 화면에서 Korean Language Pack이 설치(Installed)되어 있는지 확인해요.
4. 오른쪽 아래에 나오는 **Restart**(다시 시작) 버튼을 클릭해요.
5. 다시 열린 창의 메뉴가 `파일`, `편집`, `선택 영역`으로 시작하면 해결된 거예요.

### 창 위에 "제한 모드"(Restricted Mode)라고 나와요
- 관련: [P1 Day 2](#/day/p1-d02)

**원인:** 폴더를 처음 열 때 나온 신뢰 창에서 **아니요**를 눌렀거나 창을 닫았어요. VS Code는 모르는 폴더의 코드를 함부로 실행하지 않도록 제한 모드로 시작해요. 내가 만든 폴더는 신뢰해도 안전해요.

**해결:**

1. 편집기 맨 위의 제한 모드 안내 줄에서 **관리**(Manage) 버튼을 클릭해요. 안내 줄이 없으면 창 맨 아래 상태 표시줄의 **제한 모드** 글자를 클릭해요.
2. 열린 화면에서 **폴더 신뢰**(Trust Folder) 계열의 버튼을 클릭해요. 문구는 버전에 따라 조금 달라요.
3. 창 위쪽의 "제한 모드" 글자가 사라지면 해결된 거예요.

### 편집기 오른쪽 위에 Live Preview 아이콘이 안 보여요
- 관련: [P1 Day 2](#/day/p1-d02)

**원인:** 미리 보기 아이콘은 `.html` 파일 탭이 앞에 있을 때만 보여요. 폴더만 열려 있거나 다른 종류의 탭이 앞에 있을 수 있어요. Live Preview 확장 프로그램이 아직 설치되지 않았을 수도 있어요.

**해결:**

1. 탐색기에서 `hello.html`을 클릭해 탭을 앞으로 가져와요.
2. 오른쪽 위 모서리에 아이콘이 생겼는지 확인해요.
3. 그래도 없으면 `Ctrl + Shift + P`를 눌러 `Live Preview: Show Preview`를 입력해요. 목록에 이 이름이 하나도 없으면 확장 설치가 안 된 거예요. `Ctrl + Shift + X`로 확장 화면을 열어 **설치됨** 목록에 Live Preview가 있는지 확인하고, 없으면 5단계를 다시 해요.
4. 미리 보기 창이 열리면 해결된 거예요.

### 탐색기에 폴더가 없고 파일 하나만 열려요
- 관련: [P1 Day 2](#/day/p1-d02)

**원인:** **파일 → 파일 열기**로 `hello.html` 하나만 열었어요. 폴더가 아니라 파일을 연 상태라서 탐색기에 파일 목록이 안 보이고, Live Preview도 이 파일 하나만 다루기 어려워요.

**해결:**

1. 맨 위 메뉴 **파일 → 폴더 열기**를 클릭해요.
2. 주소 표시줄에 `C:\dev\hello`를 입력하고 `Enter`, 이어서 **폴더 선택**을 클릭해요.
3. 저장하지 않은 내용이 있다는 창이 뜨면 먼저 `Ctrl + S`로 저장해요.
4. 탐색기 맨 위에 `HELLO`가 보이고 그 아래에 파일 목록이 있으면 해결된 거예요.

### Windows 보안 경고 창(방화벽)이 떠서 허용하라고 해요
- 관련: [P1 Day 2](#/day/p1-d02)

**원인:** Live Preview가 내 컴퓨터 안에서 서버를 띄울 때, 환경에 따라 Windows 방화벽이 "이 앱의 네트워크 접근을 허용할까요?"를 물을 수 있어요. 대부분은 이 창이 뜨지 않아요(내 컴퓨터 안에서만 쓰는 서버라서 뜨지 않는 경우가 많을 것으로 보여요). 뜨는 조건과 문구는 실기로 확인하지 못했어요.

**해결:**

1. 창에 적힌 앱 이름이 Visual Studio Code(또는 Code, Node.js)이고 게시자가 Microsoft나 OpenJS Foundation인지 확인해요.
2. 허용할 네트워크 종류에서 **개인 네트워크**만 체크하고 **공용 네트워크**는 체크하지 않아요. 공용 네트워크는 카페 같은 공개된 와이파이라서 열면 안 돼요.
3. **액세스 허용**(Allow access)을 클릭해요. 허용하지 않아도 내 컴퓨터 안에서 보는 미리 보기는 보통 동작해요.
4. 미리 보기 창에 페이지가 보이면 해결된 거예요.

### Chrome이 계속 "기본 브라우저로 설정"을 물어요
- 관련: [P1 Day 2](#/day/p1-d02)

**원인:** Chrome은 기본 브라우저가 아니면 실행할 때마다 설정을 권해요. 오류가 아니에요.

**해결:**

1. 안내 줄의 **×**(닫기) 또는 **다시 묻지 않음**을 클릭해요.
2. 안내가 사라지면 해결된 거예요. 기본 브라우저는 Edge로 그대로 둬도 이 교재를 끝까지 따라갈 수 있어요.
