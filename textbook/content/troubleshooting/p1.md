# P1 문제 해결 (Day 1)

### 파일 이름이 hello.html.txt로 저장돼요 (더블클릭하면 메모장이 열려요)
- 관련: [P1 Day 1](#/day/p1-d01)

**원인:** 메모장은 저장할 때 **파일 형식**이 "텍스트 문서 (\*.txt)"로 되어 있으면 이름 끝에 `.txt`를 몰래 붙여요. 확장자는 마지막 점 뒤의 글자라서 `hello.html.txt`의 진짜 확장자는 `.txt`예요. 그래서 Windows가 웹페이지가 아니라 텍스트 문서로 보고 메모장으로 열어요. 확장자 표시가 꺼져 있으면 `hello.html`처럼 보여서 알아채기 어려워요.

**해결(그 파일이 메모장에 열려 있을 때, 가장 안전한 방법):** 메모장에서 다시 저장해요. 파일 탐색기에서 이름만 바꾸면, 열려 있는 메모장은 여전히 옛 이름(`hello.html.txt`)을 기억하고 있어서 다음에 `Ctrl + S`를 누를 때 `hello.html.txt`가 다시 생기고, 새 `hello.html`에는 고친 내용이 들어가지 않아요.

1. 메모장에서 **파일 → 다른 이름으로 저장**을 클릭해요.
2. 저장 창 위쪽 주소 표시줄의 빈 곳을 클릭하고 `C:\dev\hello`를 입력한 뒤 `Enter`를 눌러요.
3. **파일 형식**은 **모든 파일** `(*.*)`, **파일 이름**은 따옴표까지 `"hello.html"`로 입력하고 **저장**을 클릭해요. 바꿀지 묻는 창이 뜨면 **예**를 눌러요.
4. 메모장 탭(또는 제목 줄) 이름이 `hello.html`인지 확인해요.
5. 파일 탐색기 `C:\dev\hello`에서 남은 `hello.html.txt`를 한 번 클릭하고 `Delete` 키를 눌러 지워요(휴지통으로 가요). 오른쪽 클릭 메뉴의 휴지통 모양 아이콘(삭제)을 눌러도 돼요.
6. `hello.html`의 아이콘이 브라우저(Edge 또는 Chrome) 모양이면 해결된 거예요.

**해결(메모장에 열려 있지 않은 파일일 때):** 파일 탐색기에서 이름을 바꿔도 돼요.

1. 파일 탐색기에서 **보기 → 표시 → 파일 확장명**이 체크되어 있는지 확인해요. 그래야 진짜 이름이 보여요.
2. `C:\dev\hello` 폴더에서 `hello.html.txt`를 한 번 클릭해 선택하고 `F2`를 눌러요(노트북은 `Fn + F2`일 수 있어요). 오른쪽 클릭 메뉴의 **이름 바꾸기**를 눌러도 돼요.
3. 이름의 앞부분(`hello.html`)만 파랗게 선택돼요. 이 상태에서 글자를 치면 이름이 통째로 바뀌니 조심해요. `End` 키를 눌러 커서를 맨 끝으로 옮긴 뒤 `Backspace`를 4번 눌러 `.txt`를 지우고 `Enter`를 눌러요(노트북에서 `End`는 `Fn + →`일 수 있어요). 다른 방법: `Ctrl + A`로 이름 전체를 선택하고 `hello.html`을 새로 입력해요.
4. "확장명을 변경하면 파일을 사용할 수 없게 될 수도 있습니다" 경고가 뜨면 **예**를 눌러요(아래 "확장명을 변경하면…" 항목 참고).
5. 아이콘이 브라우저 모양으로 바뀌면 해결된 거예요. 다음부터는 저장할 때 파일 이름을 따옴표로 감싸 `"hello.html"`처럼 입력해요.
6. 메모장에 열어 둔 채로 이름을 이미 바꿨다면, 메모장에서 위의 "메모장에 열려 있을 때" 1~4를 한 번 더 해요.

### `C:\dev\hello`에 `hello.html`이 안 보여요 (다른 폴더에 저장됐어요)
- 관련: [P1 Day 1](#/day/p1-d01)

**원인:** 메모장의 저장 창이 `C:\dev\hello`가 아닌 곳(문서, OneDrive, 바탕 화면 등)을 가리킨 채로 저장했어요. 저장 창은 지난번에 저장한 폴더를 먼저 보여 주기 때문에, 주소 표시줄을 확인하지 않으면 엉뚱한 곳에 저장되기 쉬워요.

**해결:**

1. 메모장으로 돌아가서 **파일 → 다른 이름으로 저장**을 클릭해요.
2. 저장 창 위쪽 주소 표시줄의 빈 곳을 클릭하고 `C:\dev\hello`를 입력한 뒤 `Enter`를 눌러요. 주소 표시줄에 `C:\dev\hello`가 보이는지 확인해요.
3. **파일 형식**은 **모든 파일** `(*.*)`, **파일 이름**은 따옴표까지 `"hello.html"`로 입력하고 **저장**을 클릭해요.
4. 메모장 탭 이름이 `hello.html`인지 확인해요.
5. 파일 탐색기 `C:\dev\hello` 창에 `hello.html`이 보이면 해결이에요. 다른 폴더에 먼저 저장된 파일은 그대로 둬도 괜찮아요.

### 메모장으로 다시 열고 싶어요 (더블클릭하면 브라우저가 열려요)
- 관련: [P1 Day 1](#/day/p1-d01)

**원인:** `.html` 파일은 더블클릭하면 브라우저로 열리게 되어 있어요. 내용을 고치려면 메모장을 골라서 열어야 해요.

**해결:**

1. 파일 탐색기 `C:\dev\hello`에서 `hello.html`을 오른쪽 클릭하고 **연결 프로그램 → 메모장**을 골라요.
2. 목록에 메모장이 없으면 **다른 앱 선택**에서 메모장을 고르고 **한 번만**을 눌러요. **항상**을 누르면 더블클릭할 때도 메모장이 열리게 바뀌니 누르지 않아요.
3. 다른 방법: 메모장에서 **파일 → 열기**를 누르고, 오른쪽 아래 형식 칸을 **모든 파일** `(*.*)`로 바꾼 뒤 `C:\dev\hello\hello.html`을 골라 **열기**를 눌러요. 형식이 "텍스트 문서"로 되어 있으면 `.html` 파일이 목록에 안 보여요.
4. 메모장 탭 이름이 `hello.html`이고 내가 쓴 코드가 보이면 성공이에요.

### 확장명을 변경하면 파일을 사용할 수 없게 될 수도 있습니다 (If you change a file name extension, the file might become unusable.)
- 관련: [P1 Day 1](#/day/p1-d01)

**원인:** 파일 이름 끝의 확장자를 바꿀 때 Windows가 띄우는 확인 창이에요. 영어 원문은 "If you change a file name extension, the file might become unusable. Are you sure you want to change it?"이고, 뜻은 "확장자를 바꾸면 이 파일을 여는 앱이 달라져서 안 열릴 수도 있는데, 정말 바꿀까요?"예요. 오류가 아니라 확인 질문이에요(문구는 Windows 버전에 따라 조금 다를 수 있어요).

**해결:**

1. `hello.html.txt`를 `hello.html`로 고치는 중이라면 **예**를 눌러요. HTML 파일은 글자로만 된 파일이라 확장자를 바꿔도 내용은 그대로예요.
2. 사진(`.jpg`)이나 프로그램(`.exe`)처럼 다른 종류의 파일이라면 **아니요**를 눌러요. 확장자만 바꾼다고 파일 종류가 바뀌지는 않아요.

### Destination Folder Access Denied (대상 폴더 액세스 거부)
- 관련: [P1 Day 1](#/day/p1-d01)

**원인:** `C:\dev` 폴더를 만들 때 이 창이 뜨면, 이 컴퓨터는 `C:` 드라이브 맨 위에 폴더를 만들 때 관리자 권한을 요구하도록 설정되어 있는 거예요. 영어 원문은 "Destination Folder Access Denied — You'll need to provide administrator permission to create this folder."이고, 한국어 화면에는 "대상 폴더 액세스 거부 / 이 폴더를 만들려면 관리자 권한을 제공해야 합니다"처럼 보여요(문구는 버전에 따라 조금 다를 수 있어요). 집에서 쓰는 개인 PC는 보통 이 창 없이 바로 만들어져요.

**해결:**

1. 창의 **계속** 버튼을 눌러요.
2. 변경을 허용할지 묻는 "사용자 계정 컨트롤" 창이 뜨면 **예**를 눌러요. 내 계정이 관리자 계정이면 바로 만들어져요.
3. 관리자 비밀번호를 묻는데 모른다면(회사·학교 PC 등) 그 컴퓨터의 관리자에게 `C:\dev` 폴더를 만들어 달라고 부탁해요. 폴더만 한 번 만들어 두면 그 안에서는 권한 창 없이 작업할 수 있어요.

### You don't have permission to save in this location. (이 위치에 저장할 권한이 없어요)
- 관련: [P1 Day 1](#/day/p1-d01)

**원인:** 메모장의 저장 창이 `C:\dev\hello`가 아니라 `C:\` 맨 위(로컬 디스크 (C:))를 가리키고 있어요. Windows는 `C:\` 맨 위에 파일을 바로 저장하는 것을 막아요. 영어 원문은 "You don't have permission to save in this location. Contact the administrator to obtain permission."이고, 한국어 화면에는 "이 위치에 저장할 수 있는 권한이 없습니다"처럼 보여요(문구는 버전에 따라 조금 다를 수 있어요).

**해결:**

1. 경고 창에서 다른 폴더에 저장할지 묻는 질문이 나오면 **아니요**를 눌러 저장 창으로 돌아가요.
2. 저장 창 위쪽 주소 표시줄의 빈 곳을 클릭하고 `C:\dev\hello`를 입력한 뒤 `Enter`를 눌러요.
3. 주소 표시줄에 `C:\dev\hello`가 보이는지 확인하고 다시 **저장**을 눌러요.

### 한글이 �ȳ��ϼ��� 처럼 깨져 보여요
- 관련: [P1 Day 1](#/day/p1-d01)

**원인:** 파일을 저장한 글자 방식(인코딩)과 HTML 안에 적어 둔 `<meta charset="utf-8">`이 서로 달라요. 메모장 저장 창의 **인코딩**을 UTF-8이 아닌 다른 값(예: ANSI)으로 바꿔 저장하면, 브라우저는 UTF-8로 읽으려다 실패해서 한글을 `�` 같은 글자로 보여 줘요.

**해결:**

1. 메모장에서 **파일 → 다른 이름으로 저장**을 눌러요. 메모장을 닫았다면 "메모장으로 다시 열고 싶어요" 항목대로 먼저 열어요.
2. 저장 창 아래쪽 **인코딩**을 **UTF-8**로 고르고, 파일 이름은 따옴표까지 `"hello.html"`로 입력해 같은 곳에 저장해요.
3. "이미 있습니다. 바꾸시겠습니까?" 같은 확인 창이 뜨면 **예**를 눌러요.
4. 브라우저에서 `F5`를 눌러 새로 고쳐요. 그래도 깨지면 `<meta charset="utf-8">` 줄이 `<head>` 바로 아래에 오타 없이 있는지 확인해요.

### 고쳤는데 브라우저 화면이 그대로예요
- 관련: [P1 Day 1](#/day/p1-d01)

**원인:** 둘 중 하나예요. ① 메모장에서 저장하지 않았어요. 메모장 탭의 파일 이름 옆에 동그라미(●)나 별표(\*)가 있으면 저장하지 않은 상태예요. ② 브라우저가 예전 화면을 그대로 보여 주고 있어요. 브라우저는 파일이 바뀌어도 스스로 다시 읽지 않아요.

**해결:**

1. 메모장을 클릭하고 `Ctrl + S`를 눌러 저장해요.
2. 브라우저를 클릭하고 `F5`를 눌러요(노트북은 `Fn + F5`일 수 있어요). 주소 표시줄 왼쪽의 ↻ 버튼을 눌러도 돼요.
3. 그래도 그대로면 메모장 탭 제목과 브라우저 주소가 같은 파일(`C:\dev\hello\hello.html`)인지 확인해요. 다른 폴더의 같은 이름 파일을 고치고 있을 수 있어요. 메모장 탭 이름이 `hello.html.txt`라면 "파일 이름이 hello.html.txt로 저장돼요" 항목의 "메모장에 열려 있을 때" 방법대로 다시 저장해요.

### 영어를 쳤는데 ㅗ싀 처럼 한글이 입력돼요
- 관련: [P1 Day 1](#/day/p1-d01)

**원인:** 키보드가 한글 입력 상태예요. 한글 상태에서 `html`을 치면 `ㅗ싀`, `dev`를 치면 `ㅇㄷㅍ`처럼 입력돼요. 작업 표시줄 오른쪽 아래에 **가**가 보이면 한글, **A**가 보이면 영어 입력 상태예요.

**해결:**

1. 키보드의 `한/영` 키를 한 번 눌러요. 작업 표시줄의 **가**가 **A**로 바뀌어요.
2. 잘못 입력한 글자를 `Backspace`로 지우고 다시 입력해요.
3. 폴더 이름을 한글로 잘못 만들었다면 폴더를 클릭하고 `F2`를 눌러 이름을 다시 입력해요.

### 파일 탐색기에 보기 메뉴나 파일 확장명 항목이 안 보여요
- 관련: [P1 Day 1](#/day/p1-d01)

**원인:** 창이 좁으면 위쪽 도구 모음의 버튼 일부가 오른쪽 끝 **⋯**(더 보기) 안으로 들어가요. Windows 버전에 따라 메뉴 이름이 조금 다를 수도 있어요.

**해결:**

1. 파일 탐색기 창 오른쪽 위의 □(최대화) 버튼을 눌러 창을 크게 만들어요. **보기**가 다시 나타나요. 영어 Windows에서는 **View → Show → File name extensions**예요.
2. 그래도 없으면 도구 모음 오른쪽 끝의 **⋯** 버튼(더 보기)을 눌러 그 안에서 찾아요.
3. 다른 방법: **⋯ → 옵션**(또는 **보기 → 옵션**)을 눌러 "폴더 옵션" 창을 열고, **보기** 탭의 고급 설정 목록에서 "알려진 파일 형식의 파일 확장명 숨기기" 체크를 해제한 뒤 **확인**을 눌러요.

### 화면에 `<h1>` 같은 꺾쇠 표시가 글자 그대로 보여요
- 관련: [P1 Day 1](#/day/p1-d01)

**원인:** 둘 중 하나예요. ① 코드 전체가 꺾쇠까지 그대로 보이면, 브라우저가 이 파일을 웹페이지가 아니라 그냥 글자 문서로 읽은 거예요. 주소 표시줄의 주소가 `.txt`로 끝나면 파일 이름이 `hello.html.txt`인 경우예요. ② 한 줄에서만 `h1>`처럼 꺾쇠 일부가 보이면, 그 앞의 여는 꺾쇠 `<`를 빠뜨린 오타예요.

**해결:**

1. 주소가 `.txt`로 끝나면 "파일 이름이 hello.html.txt로 저장돼요" 항목대로 고쳐요.
2. 주소가 `.html`로 끝나면 메모장에서 꺾쇠가 보이는 줄을 찾아 `<h1>`처럼 `<`와 `>`가 짝이 맞는지 확인해요.
3. 고친 뒤 `Ctrl + S`로 저장하고 브라우저에서 `F5`를 눌러요.

### 제목이나 문장이 통째로 사라졌어요
- 관련: [P1 Day 1](#/day/p1-d01)

**원인:** 꺾쇠를 닫는 `>`를 빠뜨렸어요. 예를 들어 `<h1안녕하세요!</h1>`처럼 쓰면 브라우저는 `<` 다음부터 다음 `>`까지를 모두 표시(꺾쇠 괄호 안의 이름)로 읽어서, 그 사이의 글자를 화면에 보여 주지 않아요.

**해결:**

1. 메모장에서 사라진 글자가 있던 줄을 찾아요.
2. 여는 표시가 `<h1>`, `<p>`처럼 `>`로 닫혀 있는지 확인하고, 빠진 `>`를 넣어요.
3. `Ctrl + S`로 저장하고 브라우저에서 `F5`를 눌러요.

### 큰 제목 아래 글씨까지 전부 크게 보여요
- 관련: [P1 Day 1](#/day/p1-d01)

**원인:** 큰 제목을 닫는 `</h1>`에서 `/`를 빠뜨려 `<h1>`이 두 번 들어갔어요. 브라우저는 제목이 끝나지 않았다고 보고 뒤의 글까지 모두 큰 제목처럼 그려요.

**해결:**

1. 메모장에서 제목 줄이 `<h1>안녕하세요!</h1>`처럼 끝에 `</h1>`(빗금 `/` 포함)로 닫혀 있는지 확인해요.
2. 고친 뒤 `Ctrl + S`로 저장하고 브라우저에서 `F5`를 눌러요.
