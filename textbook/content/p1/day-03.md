## 📖 개념 이해

### 태그, 요소, 속성: 포장 상자의 라벨

**비유부터 볼게요.** 택배 상자에는 "여기부터 깨지기 쉬운 물건"을 알리는 스티커가 있고, 상자를 닫는 곳에는 "여기까지"를 알리는 표시가 있어요. 상자에는 받는 사람 같은 이름표(정보)도 붙어요. HTML도 비슷해요. 글을 "여기부터 여기까지가 큰 제목이에요" 하고 표시로 감싸요.

**정확한 정의는 이래요.**

- **[[태그]]**(tag)는 `<p>`처럼 꺾쇠 괄호로 감싼 표시예요. 여는 태그 `<p>`와 앞에 `/`가 붙은 닫는 태그 `</p>`가 짝을 이뤄 범위를 정해요.
- **[[요소]]**(element)는 여는 태그, 내용, 닫는 태그를 합친 한 덩어리예요. `<h1>안녕하세요</h1>` 전체가 `h1` 요소 하나예요.
- **[[속성]]**(attribute)은 여는 태그 안에 `이름="값"` 모양으로 적어서 요소에 정보를 더하는 거예요. `<html lang="ko">`에서 `lang="ko"`가 속성이에요. 값은 항상 큰따옴표로 감싸요.

닫는 태그가 없는 요소도 있어요. `<meta charset="utf-8">`처럼 감쌀 내용이 없는 요소예요. 이런 요소는 여는 태그 하나로 끝나요.

```html
<p class="intro">안녕하세요</p>
```

- 여는 태그: `<p class="intro">`
- 속성: `class="intro"` (이름 `class`, 값 `intro`)
- 내용: `안녕하세요`
- 닫는 태그: `</p>`
- 요소: 위 네 가지를 모두 합친 줄 전체

### HTML 문서의 뼈대

모든 HTML 파일은 같은 뼈대로 시작해요. Day 1에서 맛보기로 썼던 모양이에요. 오늘 한 줄씩 정확히 배워요.

- **[[DOCTYPE]]**(독타입): 파일 맨 첫 줄 `<!doctype html>`이에요. 브라우저에게 "이 문서는 요즘 표준 HTML이에요"라고 알려요. 대문자 `<!DOCTYPE html>`도 같은 뜻이에요.
- `<html lang="ko">`: 문서 전체를 감싸요. `lang="ko"`는 "한국어 문서"라는 뜻이고, 브라우저가 번역 제안을 할지 판단하는 데도 써요.
- `<head>`: 화면에는 안 보이는 설정을 적는 칸이에요.
- `<meta charset="utf-8">`: 이 파일이 UTF-8로 저장되었다는 표시예요. 한글이 깨지지 않게 해 줘요.
- `<meta name="viewport" content="width=device-width, initial-scale=1">`: 휴대폰 화면에 맞추는 설정이에요. 지금은 그대로 쓰고, 뜻은 Day 13에서 배워요.
- `<title>`: 브라우저 탭에 보이는 제목이에요.
- `<body>`: 화면에 보이는 내용을 적는 칸이에요.

### 제목과 문단, 주석

**비유:** 책에는 큰 제목, 장 제목, 절 제목이 있고 본문이 있어요. 목차를 보면 구조가 한눈에 보이죠. HTML 제목도 `h1`(가장 큰 제목)부터 `h6`(가장 작은 제목)까지 여섯 단계가 있어요.

**규칙 세 가지**를 지켜요.

1. 한 페이지에 `h1`은 하나만 써요. 이 페이지의 가장 중요한 제목이에요.
2. 단계를 건너뛰지 않아요. `h1` 다음에 `h2`, 그 안에 `h3`이에요. 크기를 바꾸려고 `h3`을 고르면 안 돼요. 크기는 Day 9부터 CSS로 정해요.
3. 보통 글은 `<p>`(문단)로 감싸요.

**[[주석]]**(comment)은 사람이 읽으려고 남기는 메모예요. `<!-- 메모 -->`로 쓰고, 화면에 나타나지 않아요. 나중의 내가 "왜 이렇게 했지?" 하고 궁금할 때 도움이 돼요.

### 공백이 한 칸으로 합쳐져요

HTML에서는 빈칸을 여러 개 쳐도, `Enter`로 줄을 바꿔도 브라우저 화면에서는 **빈칸 한 칸**으로 합쳐 보여요. 줄을 나누려면 `<p>`를 새로 만들어요. 코드를 보기 좋게 정리하려고 줄 앞에 빈칸을 넣는 것을 **[[들여쓰기]]**(indent)라고 해요. 들여쓰기는 사람을 위한 것이라 화면 결과는 바뀌지 않아요. 이 교재는 한 단계마다 스페이스 2칸을 써요.

### Emmet: 약어로 뼈대 만들기

뼈대는 늘 같은 모양이라서, 매번 입력하면 지루하고 오타도 나요. **[[Emmet]]**(에밋)은 짧은 약어를 입력하면 긴 HTML 코드로 펼쳐 주는 기능이에요. VS Code에 기본으로 들어 있어요. `.html` 파일에서 `!`를 입력하고 `Tab`을 누르면 뼈대가 한 번에 만들어져요. 다만 타이핑을 줄여 줄 뿐이라서, 만들어진 코드의 뜻은 직접 알고 있어야 해요.

**Editor: Tab Size** 칸에 `2`가 보여요. 아래 4단계에서 새 파일을 열면 맨 아래 상태 표시줄에 `공백: 2`가 보여요.

**무엇을:**

### 5단계 · 뼈대 읽고 고치기 (4분)

Emmet이 만든 코드는 개념 이해에서 배운 뼈대와 거의 같아요. 달라 보이는 곳이 세 군데예요.

- `<!DOCTYPE html>`은 대문자로 만들어졌어요. 교재는 소문자 `<!doctype html>`을 쓰지만 뜻은 같아요.
- `charset="UTF-8"`은 대문자예요. 소문자 `utf-8`과 뜻이 같아요.
- `initial-scale=1.0`은 `1`과 같은 값이에요.

**어디서:** `index.html` 편집기

**무엇을:**

1. 두 번째 줄 `<html lang="en">`의 `en`을 `ko`로 바꿔요. `en`은 영어, `ko`는 한국어예요.
2. `<title>Document</title>`의 `Document`를 `달빛곰 방송국`으로 바꿔요. 닉네임을 바꿔 써도 돼요.
3. `Ctrl + S`를 눌러 저장해요.

:::success
두 줄이 `<html lang="ko">`와 `<title>달빛곰 방송국</title>`이 돼요. 탭의 ●가 사라져요.
:::

### 6단계 · 본문 쓰기 (12분)

이제 `<body>` 안에 화면에 보일 글을 써요. 글 내용(닉네임, 소개 문장)은 내 것으로 바꿔도 돼요. 태그 이름은 바꾸지 않아요.

**어디서:** `index.html` 편집기, `<body>` 줄과 `</body>` 줄 사이

**무엇을:** 먼저 `<h1>` 줄만 직접 입력해 봐요. `<h1>`을 입력하면 닫는 태그 `</h1>`이 저절로 생겨요. 그 사이에 `안녕하세요, 달빛곰이에요!`를 쓰고 `End` 키로 줄 끝으로 가서 `Enter`를 눌러요. 나머지는 아래 코드를 보고 같은 방식으로 입력해요. 직접 입력이 어려우면 `Ctrl + A`로 파일 전체를 선택하고 아래 코드를 복사해서 붙여 넣어도 돼요.

📄 C:\dev\my-creator-site\index.html
```html
<!doctype html>
<html lang="ko">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>달빛곰 방송국</title>
</head>
<body>
  <!-- 홈 페이지: 인사와 방송 소개 -->
  <h1>안녕하세요, 달빛곰이에요!</h1>
  <p>게임, 토크, 음악을 넘나드는 버라이어티 스트리머예요. 매주 월·수·금·토에 방송해요.</p>
  <h2>이런 방송을 해요</h2>
  <h3>게임 방송</h3>
  <p>신작부터 레트로 게임까지, 시청자와 함께 즐겨요.</p>
  <h3>토크 방송</h3>
  <p>사연을 읽고 수다를 떨어요. 편하게 놀러 오세요.</p>
  <h3>음악 방송</h3>
  <p>기타를 치며 신청곡을 불러 드려요.</p>
</body>
</html>
```
코드 줄마다 뜻을 짚어 봐요.

- `<!-- 홈 페이지: 인사와 방송 소개 -->`는 주석이에요. 화면에 나타나지 않아요.
- `<h1>`은 이 페이지의 가장 큰 제목 하나예요.
- `<p>`는 문단이에요. 소개 문장이 들어가요.
- `<h2>이런 방송을 해요</h2>`는 중간 제목이에요.
- `<h3>` 세 개는 `h2` 아래의 작은 제목이에요. 각각 뒤에 `<p>` 문단이 하나씩 이어져요.

:::success
편집기의 코드가 위 모양과 같아요. 줄마다 색이 입혀져 있고, 탭 이름 옆의 ●는 `Ctrl + S`로 저장하면 사라져요.
:::

탭 제목을 직접 보고 싶다면 파일 탐색기에서 `C:\dev\my-creator-site\index.html`을 더블클릭해 브라우저로 열어요. 브라우저 탭에 `달빛곰 방송국`이 보여요.

### 과제 1 · 고장 난 HTML 고치기 (쉬움 ⭐, 15분)

아래 코드에는 문제가 세 개 있어요. 눈으로 읽어서 찾아 보세요. 각 문제가 화면에서 어떻게 보일지도 짐작해 봐요.

```html
<!doctype html>
<html lang="ko">
<head>
  <meta charset="utf-8">
  <titel>고장 난 페이지</title>
</head>
<body>
  <h1>고장 난 페이지
  <p class="intro>이 페이지에는 문제가 세 개 있어요.</p>
  <p>다 찾았나요?</p>
</body>
</html>
```

- 힌트 1: 여는 태그와 닫는 태그의 이름이 같은지 봐요.
- 힌트 2: 제목은 어디서 끝나나요?
- 힌트 3: 속성의 따옴표는 짝이 맞나요?

### 과제 2 · 제목 단계 점검 (보통 ⭐⭐, 10분)

오늘 만든 `index.html`의 제목 구조를 들여 쓴 목록으로 그려 보세요. 가장 큰 제목 아래에 중간 제목, 그 아래에 작은 제목을 들여 써요. 파일은 바뀌지 않아요. 종이나 메모장에 적어도 돼요.

## ✅ 정답

:::answer 과제 1 정답 · 고장 난 HTML 고치기
문제는 세 군데예요.

- 5번째 줄: `<titel>`은 철자가 틀렸어요. `<title>`이어야 해요. 브라우저가 모르는 태그로 보고 탭 제목으로 쓰지 않아요. 그래서 탭에는 파일 이름이 대신 보이고, "고장 난 페이지" 글자가 본문에 보통 글자로 한 번 더 나타나요.
- 8번째 줄: `<h1>`을 열고 `</h1>`로 닫지 않았어요. 닫는 태그가 없으면 아래 문단까지 모두 큰 제목 안에 들어가서 커져요.
- 9번째 줄: `class="intro>`는 닫는 따옴표가 빠졌어요. 따옴표의 짝이 안 맞으면 브라우저가 다음 따옴표를 찾을 때까지 모두 속성 값으로 읽어요. 따옴표가 더 없으니 이 문단과 그 아래 내용이 화면에서 통째로 사라져요.

고친 코드:

```html
<!doctype html>
<html lang="ko">
<head>
  <meta charset="utf-8">
  <title>고장 난 페이지</title>
</head>
<body>
  <h1>고장 난 페이지</h1>
  <p class="intro">이 페이지에는 문제가 세 개 있어요.</p>
  <p>다 찾았나요?</p>
</body>
</html>
```

**왜 이렇게 하나요?** 태그 이름은 정해진 철자만 알아봐요. 닫는 태그와 따옴표는 범위를 정하는 표시라서, 하나라도 빠지면 그 뒤의 구조 전체가 틀어져요. 화면이 이상할 때는 가장 먼저 이 세 가지를 확인하세요.
:::

:::answer 과제 2 정답 · 제목 단계 점검
```text
h1  안녕하세요, 달빛곰이에요!
  h2  이런 방송을 해요
    h3  게임 방송
    h3  토크 방송
    h3  음악 방송
```

**왜 이렇게 하나요?** `h1`은 하나, 그 아래 `h2`가 하나, 그 아래 `h3`가 셋이에요. 단계를 건너뛰지 않았어요. 이런 목록처럼 제목만 읽어도 페이지 구조가 보이게 쓰는 것이 좋아요.
:::

## 🧯 자주 막히는 곳

모든 문제와 드문 경우는 [문제 해결 모음](#/page/troubleshooting)에 있어요.

### `!`를 쳐도 Emmet 제안이 안 떠요

**원인:** Emmet은 VS Code가 파일을 HTML로 알아볼 때만 동작해요. 파일을 `.html`로 만들지 않았거나(아직 저장 전 새 파일), 한글 입력 상태라서 `!`를 다른 글자로 입력했을 수 있어요. 제안 목록이 떴다가 사라진 경우도 있어요.

**해결:**

1. 창 맨 아래 상태 표시줄 오른쪽에 `HTML`이라고 보이는지 확인해요. `일반 텍스트`(Plain Text)면 `index.html`로 저장하지 않은 파일이에요. 글자를 클릭해 **HTML**을 고르거나, 탐색기에서 `index.html`을 새로 만들어요.
2. `한/영` 키로 영어 입력 상태(작업 표시줄 오른쪽 아래 **A**)로 바꾸고 `!`를 다시 입력해요.
3. 제안 목록이 안 보이면 `Ctrl + Space`를 눌러 목록을 다시 열고, `!` 항목을 고르고 `Tab`을 눌러요.
4. `<!DOCTYPE html>`로 시작하는 뼈대가 생기면 해결된 거예요.

### index.html을 엉뚱한 폴더(C:\dev\hello)에 만들었어요

**원인:** VS Code에 `hello` 폴더가 열려 있는 상태에서 새 파일을 만들면 그 폴더에 만들어져요. 탐색기 맨 위 이름이 `HELLO`이면 폴더를 잘못 연 거예요.

**해결:**

1. VS Code 탐색기 맨 위 이름을 읽어요. `MY-CREATOR-SITE`가 아니라 `HELLO`면 잘못 열린 거예요.
2. **파일 → 폴더 열기**를 클릭해 `C:\dev\my-creator-site`를 열어요.
3. 파일 탐색기에서 `C:\dev\hello\index.html`을 한 번 클릭하고 `Delete` 키로 지워요(휴지통으로 가요). 이 파일은 오늘 쓰지 않아요.
4. `my-creator-site` 폴더에서 4단계부터 다시 해요. 탐색기에 `MY-CREATOR-SITE` 아래 `index.html`이 보이면 해결된 거예요.

### 큰 제목 아래의 글씨까지 전부 크게 보여요

**원인:** 제목이나 문단의 닫는 태그 `</h1>`을 빠뜨렸거나 `/`를 빠뜨려서 `<h1>`으로 썼어요. 브라우저가 "제목이 아직 안 끝났구나" 하고 아래 글까지 모두 제목으로 보여 줘요.

**해결:**

1. 큰 글씨가 시작되는 줄부터 위로 거슬러 올라가며, 열었는데 닫지 않은 태그를 찾아요.
2. 그 줄 끝에 `</h1>`처럼 닫는 태그를 써요. `/`가 빠져 `<h1>`이라고 되어 있다면 `<h1>`을 `</h1>`로 고쳐요.
3. `Ctrl + S`로 저장하고 미리 보기를 확인해요.
4. 제목만 크고 아래 글은 보통 크기로 돌아오면 해결된 거예요.

### Edge가 "이 페이지를 번역하시겠습니까?"라고 물어요

**원인:** `<html lang="en">`이 그대로 있어서 브라우저가 이 문서를 영어로 알고 있어요. 한글 문서인데 영어라고 적혀 있으니 번역을 권해요.

**해결:**

1. `index.html`의 `<html lang="en">`을 `<html lang="ko">`로 바꿔요.
2. `Ctrl + S`로 저장하고, 브라우저에서 `F5`를 눌러 새로 고침해요.
3. 번역 제안이 더 뜨지 않으면 해결된 거예요.

### `</h1></h1>`처럼 닫는 태그가 두 개가 돼요

**원인:** VS Code는 `<h1>`을 입력하고 `>`를 치면 닫는 태그 `</h1>`을 자동으로 만들어 줘요. 이걸 모르고 닫는 태그를 직접 한 번 더 입력하면 겹쳐요.

**해결:**

1. 줄 끝에 닫는 태그가 두 개 붙은 곳을 찾아요.
2. 하나를 지워서 `<h1>안녕하세요</h1>`처럼 한 번만 남겨요.
3. 앞으로는 여는 태그를 입력한 직후 글을 쓰고 `End` 키로 닫는 태그 뒤로 빠져나가요.
4. 줄에 닫는 태그가 하나만 있으면 해결된 거예요.

### Tab Size를 2로 바꿨는데 이미 있는 줄은 4칸 그대로예요

**원인:** 설정은 앞으로 만드는 들여쓰기에만 적용돼요. 이미 입력된 줄은 그대로 있어요. Emmet으로 뼈대를 만든 뒤에 설정을 바꿨다면 뼈대는 4칸이에요. 화면 결과는 달라지지 않지만 교재 코드와 모양이 달라요.

**해결:**

1. 파일 전체를 지우고 4단계에서 `!` + `Tab`으로 뼈대를 다시 만들면 2칸으로 만들어져요.
2. 또는 맨 아래 상태 표시줄의 `공백: 4`를 클릭하고 **공백으로 들여쓰기 변환**(Convert Indentation to Spaces) 계열 항목을 골라요. 이름은 버전에 따라 조금 다를 수 있어요.
3. 줄 앞 칸 수가 달라도 화면은 같아요. 교재 코드와 똑같이 맞추지 않아도 괜찮아요.
