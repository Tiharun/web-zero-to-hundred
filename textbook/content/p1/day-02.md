## 📖 개념 이해

### 코드 편집기와 VS Code

**비유부터 볼게요.** 메모장이 연필과 종이라면, 코드 편집기는 맞춤법 검사와 색연필, 서류철까지 갖춘 작업대예요. 같은 글을 쓰는 도구인데, 코드를 쓸 때 필요한 도움이 훨씬 많아요.

**정확한 정의는 이래요.** **[[VS Code]]**(브이에스 코드)는 Microsoft가 무료로 만든 코드 편집기예요. 정식 이름은 Visual Studio Code예요. 메모장처럼 글자만 저장하는 텍스트 편집기인데, 코드에 색을 입히고, 폴더 전체를 한 창에서 다루고, 확장 프로그램으로 기능을 더할 수 있어요.

어제 메모장으로 만든 파일은 이름이 `hello.html`이었죠. 오늘부터는 같은 파일을 VS Code로 열어 고쳐요. 파일 자체는 달라지지 않아요. 글자가 담긴 파일을 여는 도구만 바뀌는 거예요.

:::info 실무에서는
웹 개발자는 대부분 코드 편집기로 일해요. 회사마다 쓰는 편집기가 다르지만 VS Code는 가장 널리 쓰이는 것 중 하나예요. 이 교재의 모든 프로젝트를 VS Code로 만들어요.
:::

### 확장 프로그램: 휴대폰의 앱처럼

**비유:** 휴대폰에 앱을 설치해 기능을 더하듯이, VS Code에도 작은 프로그램을 끼워 넣어 기능을 더해요.

**정의:** **[[확장 프로그램]]**(extension)은 프로그램에 나중에 끼워 넣어 기능을 더하는 작은 프로그램이에요. VS Code에서는 왼쪽의 **확장** 아이콘(`Ctrl + Shift + X`)에서 찾아 설치해요. 오늘 두 개를 설치해요.

- **한국어 팩**: 메뉴와 안내를 한국어로 바꿔요.
- **Live Preview**: 웹페이지 미리 보기를 더해 줘요.

확장 프로그램은 누구나 만들어 올릴 수 있어서, 이름이 비슷한 가짜가 있을 수 있어요. 그래서 설치 전에 **게시자**(만든 곳) 이름을 꼭 확인하는 습관을 들여요. 오늘 설치할 두 개의 게시자는 모두 **Microsoft**예요.

### 명령 팔레트와 자동 저장

**[[명령 팔레트]]**(command palette)는 VS Code의 거의 모든 기능을 이름으로 찾아 실행하는 입력 칸이에요. `Ctrl + Shift + P`를 누르면 화면 위쪽에 열려요. 메뉴가 어디 있는지 몰라도 기능 이름의 일부만 치면 목록이 좁혀져서, 앞으로 가장 자주 쓰게 될 키예요.

**[[자동 저장]]**(auto save)은 고친 내용을 `Ctrl + S`를 누르지 않아도 잠시 뒤 저절로 파일에 저장해 주는 기능이에요. 꺼져 있으면 저장하지 않은 파일의 탭에 동그라미(●)가 보여요.

### Live Preview: 내 컴퓨터 안의 작은 서버

Day 1에서 파일을 더블클릭하면 주소가 `file:///C:/dev/hello/hello.html`이었어요. 브라우저가 내 컴퓨터의 파일을 바로 열어 준 거예요. 이 방법은 간단하지만, 나중에 만들 기능 중에는 진짜 웹 주소처럼 서버가 파일을 보내 줘야 동작하는 것들이 있어요.

**[[Live Preview]]**(라이브 프리뷰)는 Microsoft가 만든 VS Code 확장 프로그램이에요. 내 컴퓨터 안에서 작은 서버를 띄워서 `http://127.0.0.1:3000/hello.html` 같은 주소로 파일을 보내 줘요. 끝의 숫자 `3000`은 컴퓨터마다 달라도 돼요. `127.0.0.1`은 "내 컴퓨터 자신"을 가리키는 주소이고, 이 서버는 내 컴퓨터 안에서만 열려서 다른 사람은 볼 수 없어요. 고치고 저장하면 미리 보기 화면이 저절로 새로 고쳐지는 것도 장점이에요.

## 🛠️ 따라하기

모두 9단계예요. 설치 화면은 버전에 따라 글자나 순서가 조금 다를 수 있어요(작성 기준일 2026-11). 글자가 조금 달라도 같은 위치의 같은 뜻의 선택지를 고르면 돼요.

### 1단계 · VS Code 설치 파일 내려받기 (5분)

**어디서:** 브라우저(Edge 또는 Chrome)의 주소 표시줄

**무엇을:**

1. 주소 표시줄에 `https://code.visualstudio.com/`을 입력하고 `Enter`를 눌러요.
2. 화면의 **Download for Windows** 버튼을 클릭해요.
3. 내려받기가 끝나면 브라우저 오른쪽 위에 내려받은 파일 알림이 떠요. 파일 이름이 `VSCodeUserSetup`으로 시작하는지 확인해요. 알림이 안 보이면 `Ctrl + J`를 눌러 다운로드 목록을 열어요.

:::success
다운로드 목록에 `VSCodeUserSetup-` 뒤에 숫자가 붙은 `.exe` 파일이 보여요. 이 파일은 관리자 권한 없이 내 계정에만 설치하는 **User setup**이에요. 파일 이름이 `VSCodeSetup`으로 시작하면 관리자 권한이 필요한 System setup이에요. 아래 🧯 자주 막히는 곳의 "관리자 암호를 물어요"를 보세요. 다운로드 폴더에서 파일이 안 보이면 같은 곳의 "설치 파일이 안 보여요"를 보세요.
:::

### 2단계 · 설치 마법사 따라가기 (10분)

**어디서:** 브라우저의 다운로드 목록 또는 알림

**무엇을:** 내려받은 `VSCodeUserSetup-….exe`를 클릭(또는 더블클릭)해서 실행해요. 아래 순서대로 고르고 **다음**을 눌러요.

1. "Windows의 PC 보호" 같은 파란 경고 창이나 사용자 계정 컨트롤 창이 뜨면, 게시자가 **Microsoft Corporation**인지 확인하고 진행해요. 문구와 진행 방법은 아래 🧯 자주 막히는 곳의 두 번째 항목(파란 "Windows의 PC 보호" 창)에 있어요.
2. 사용권 계약 화면에서 **동의합니다**를 고르고 **다음**을 눌러요.
3. 설치 위치와 시작 메뉴 폴더 화면은 바꾸지 않고 **다음**을 눌러요.
4. **추가 작업 선택** 화면(영어: Select Additional Tasks)에서 이렇게 해요.
   - "탐색기 … 상황에 맞는 메뉴에 'Code(으)로 열기' 작업 추가" 항목이 두 개 있어요. 두 개 모두 체크해요. 파일을 오른쪽 클릭했을 때와 폴더를 오른쪽 클릭했을 때 쓰는 메뉴예요. 나중에 폴더를 오른쪽 클릭해서 바로 VS Code로 열 수 있어요.
   - "PATH에 추가(다시 시작한 후 사용 가능)"는 체크된 그대로 둬요. 터미널에서 `code` 명령을 쓰기 위한 설정이에요.
5. **설치 준비 완료** 화면에서 **설치**를 눌러요. 1~2분 걸려요.
6. Copilot CLI 설치를 묻는 화면이 나오면 "Don't add the copilot command"(copilot 명령을 추가하지 않음)에 해당하는 선택지를 골라요. Copilot CLI는 이 교재에서 쓰지 않는 별도 제품이에요. 이 화면은 버전에 따라 안 나올 수도 있어요.
7. **설치 완료** 화면에서 **Visual Studio Code 실행**에 체크하고 **종료**를 눌러요.

:::success
VS Code 창이 열려요. 창 맨 위에 `시작`(Welcome) 탭이 보이고, 메뉴는 아직 영어(File, Edit, Selection …)일 수 있어요. 한국어로 바꾸는 건 4단계에서 해요.
:::

### 3단계 · VS Code 화면 처음 둘러보기 (4분)

**어디서:** 방금 열린 VS Code 창

**무엇을:** 마우스만 움직여서 아래 위치를 눈으로 찾아봐요. 아직 아무것도 누르지 않아도 돼요.

- 창 맨 왼쪽의 세로 줄에 아이콘이 여러 개 있어요. 이 줄을 **활동 막대**라고 불러요. 맨 위가 **탐색기**(파일 모양), 그 아래가 검색, 소스 제어, 실행 및 디버그, **확장**(네모 네 개 모양)이에요.
- 창 맨 아래 가로 줄은 **상태 표시줄**이에요. 지금 열려 있는 파일의 정보가 나와요.
- 창 가운데 넓은 곳은 **편집기**예요. 파일을 열면 이곳에 탭으로 열려요.
- 오른쪽에 채팅(Chat) 창이 보이면 닫아도 돼요. 이 교재는 쓰지 않아요(버전에 따라 보이지 않을 수 있어요).

마지막으로 설치된 버전을 확인해요. 맨 위 메뉴 **Help → About**(영어 메뉴)을 클릭하면 작은 창에 `Version: 1.…`처럼 버전 번호가 보여요. 한국어로 바꾼 뒤에는 **도움말 → 정보**예요. 이 교재는 VS Code 버전을 고정하지 않고 최신 버전을 쓰니(작성 기준일 2026-11), 숫자가 달라도 괜찮아요.

:::success
활동 막대, 상태 표시줄, 편집기 자리를 찾았고, 정보 창에 버전 번호가 보여요. 환영 화면의 **시작** 탭은 탭 오른쪽 `×`를 눌러 닫아도 돼요.
:::

### 4단계 · 한국어 팩 설치 (6분)

**어디서:** VS Code 활동 막대의 **확장** 아이콘(네모 네 개 모양). 단축키는 `Ctrl + Shift + X`예요.

**무엇을:**

1. **확장** 아이콘을 클릭해요. 왼쪽에 검색 칸이 있는 목록이 열려요.
2. 검색 칸에 `Korean Language Pack`을 입력해요.
3. 결과에서 이름이 **Korean Language Pack for Visual Studio Code**이고 게시자가 **Microsoft**인 항목을 클릭해요. 게시자 이름은 항목 이름 아래줄에 보여요.
4. 오른쪽에 상세 화면이 열리면 **Install**(설치) 버튼을 클릭해요.
5. 설치가 끝나면 오른쪽 아래에 알림이 떠요. **Change Language and Restart**(언어 변경 및 다시 시작) 버튼을 클릭해요.

:::success
VS Code가 한 번 꺼졌다 다시 켜지고, 맨 위 메뉴가 **파일, 편집, 선택 영역, 보기 …** 처럼 한국어로 바뀌어요. 알림을 놓쳤거나 영어로 남았으면 아래 🧯 자주 막히는 곳의 "한국어 팩을 설치했는데 메뉴가 영어예요"를 보세요.
:::

### 5단계 · Live Preview 설치 (4분)

**어디서:** VS Code의 **확장** 화면(`Ctrl + Shift + X`)

**무엇을:**

1. 검색 칸에 들어 있는 글자를 지우고 `Live Preview`를 입력해요.
2. 결과에서 이름이 **Live Preview**이고 게시자가 **Microsoft**인 항목을 클릭해요. 이름이 비슷한 다른 게시자의 항목(예: Live Server)은 오늘은 쓰지 않아요.
3. 상세 화면의 **설치** 버튼을 클릭해요.
4. 설치가 끝나면 상세 화면 오른쪽 아래쪽(**추가 정보** 부분)에서 식별자가 `ms-vscode.live-server`인지 확인해요(위치와 이름은 버전에 따라 조금 다를 수 있어요).

:::success
**설치** 버튼이 있던 자리에 **제거**(또는 톱니바퀴 아이콘)가 보여요. 왼쪽 확장 목록의 **설치됨** 아래에 Korean Language Pack과 Live Preview가 둘 다 보여요.
:::

### 6단계 · 폴더 열기 (7분)

VS Code는 파일 하나가 아니라 **폴더 하나**를 열어서 쓰는 도구예요. 폴더 안의 모든 파일이 왼쪽 목록에 보이기 때문에 파일을 오가기 쉬워요.

**어디서:** VS Code 맨 위 메뉴

**무엇을:**

1. **파일 → 폴더 열기**를 클릭해요(영어: **File → Open Folder**).
2. 폴더 선택 창의 주소 표시줄 빈 곳을 클릭하고 `C:\dev\hello`를 입력한 뒤 `Enter`를 눌러요.
3. 창 오른쪽 아래의 **폴더 선택** 버튼을 클릭해요.
4. "이 폴더에 있는 파일의 작성자를 신뢰합니까?"처럼 묻는 창이 뜨면 **예, 작성자를 신뢰합니다**(영어: **Yes, I trust the authors**)를 클릭해요. 내가 직접 만든 폴더라서 안전해요. 문구는 버전에 따라 조금 다를 수 있어요.

:::success
왼쪽 **탐색기**에 맨 위 이름 `HELLO`가 보이고, 그 아래에 `favorites.html`과 `hello.html`이 보여요(이름순으로 정렬돼요). 창 맨 위 제목 줄에도 `hello`가 들어 있어요. 폴더 이름 없이 파일 하나만 열렸다면 아래 🧯 자주 막히는 곳의 "탐색기에 폴더가 없고 파일 하나만 열려요"를 보세요.
:::

:::warn 제한 모드가 되었다면
신뢰 창에서 **아니요**를 눌렀다면 창 맨 위에 "제한 모드"(Restricted Mode) 안내가 보여요. 파일을 보고 고치는 데는 문제없지만, 일부 확장 프로그램 기능이 꺼져요. 안내 줄의 **신뢰 관리**(Manage) 버튼을 눌러 신뢰로 바꿔요. 자세한 방법은 아래 🧯 자주 막히는 곳에 있어요.
:::

### 7단계 · 파일을 고치고 저장하기, 자동 저장 켜기 (7분)

**어디서:** VS Code 왼쪽 탐색기, 그리고 편집기

**무엇을:**

1. 탐색기에서 `hello.html`을 클릭해요. 가운데 편집기에 코드가 탭으로 열려요. 글자마다 색이 입혀져 보여요. 태그와 글자의 색이 달라서 읽기 쉬워요.
2. `<body>` 안의 첫 번째 `<p>` 줄을 찾아서, 줄 안의 글자를 모두 `<p>이제 VS Code로 고치고 있어요.</p>`로 바꿔요. 어제 쓴 문장은 사람마다 달라서, 줄 모양만 같으면 돼요.
3. 탭 이름 오른쪽(`×` 자리)에 동그라미 ●가 생긴 것을 확인해요. 저장하지 않았다는 표시예요.
4. `Ctrl + S`를 눌러요.
5. 맨 위 메뉴 **파일**을 클릭하고 **자동 저장**을 클릭해요(영어: **File → Auto Save**).
6. 같은 문장 끝에 글자를 하나 더 입력한 뒤 1~2초 기다려요.

VS Code는 `<h1>` 같은 여는 태그를 쓰고 `>`를 입력하면 닫는 태그 `</h1>`을 저절로 만들어 줘요. 이미 있는 줄을 고칠 때는 영향이 없어요. 새로 쓸 때는 과제 1의 안내를 보세요.

:::success
4번에서 `Ctrl + S`를 누르면 동그라미(●)가 사라지고 `×`로 돌아와요. 5번 뒤에 **파일** 메뉴를 다시 열면 **자동 저장** 앞에 체크 표시(✓)가 있어요. 6번에서는 저장 키를 누르지 않았는데도 잠시 뒤 ●가 저절로 사라져요.
:::

:::tip 상태 표시줄의 낯선 글자들
창 맨 아래 상태 표시줄에 `UTF-8`(어제 배운 글자 저장 방식), `CRLF`, `HTML`이 보여요. `CRLF`는 Windows 방식 줄바꿈이라는 뜻이고 그대로 두면 돼요. `HTML`은 이 파일을 HTML 코드로 읽고 있다는 뜻이에요.
:::

### 8단계 · Live Preview로 미리 보기 (7분)

**어디서:** VS Code 편집기에 `hello.html` 탭이 앞에 보이는 상태

**무엇을:**

1. 편집기 오른쪽 위 모서리에서 미리 보기 아이콘(**Show Preview**, 돋보기 모양이 있는 화면 아이콘)을 클릭해요. 아이콘 모양과 이름은 버전에 따라 조금 다를 수 있어요.
2. 아이콘이 안 보이면 `Ctrl + Shift + P`로 명령 팔레트를 열고 `Live Preview: Show Preview`를 입력해서 나오는 항목을 `Enter`로 실행해요. 비슷한 이름에 `(Internal Browser)`나 `(External Browser)`가 붙은 항목이 따로 보이면, 괄호 없이 `Show Preview`만 있는 항목이나 `Internal Browser`가 붙은 항목을 골라요. `External Browser`는 Edge 같은 별도 브라우저로 열어요.
3. 편집기 옆에 미리 보기 창이 열려요. 창 위쪽의 주소 칸을 읽어 봐요.
4. 편집기에서 `<h1>` 안의 글자를 바꾸고 `Ctrl + S`로 저장해요(자동 저장이 켜져 있으면 1초쯤 기다려도 돼요).

:::success
미리 보기 창에 큰 제목과 방금 고친 문장이 보여요. 주소 칸에는 `http://127.0.0.1:` 뒤에 숫자(예: `3000`), 그리고 `/hello.html`이 보여요. 4번에서는 미리 보기 창의 제목이 저절로 바뀌어요. 코드와 결과를 한 화면에서 나란히 볼 수 있어요.
:::

:::tip 미리 보기 사용법 (앞으로 계속 써요)
- 미리 보기는 고치면 저절로 바뀌어요. 새로 고침 키는 필요 없어요. 안 바뀌면 파일 탭의 ●(저장 안 됨)를 보고 `Ctrl + S`를 눌러요. 그래도 그대로면 미리 보기 창을 닫고 위 1~2처럼 다시 열어요.
- VS Code 안에서는 `F5`와 `Ctrl + F5`를 누르지 마세요. 이 키는 VS Code에서 프로그램 실행(디버그)이라 엉뚱한 선택 창이 떠요. 이 두 키는 **브라우저 탭**을 클릭한 뒤에만 써요.
- 파일을 더블클릭해서 연 브라우저 탭은 자동으로 바뀌지 않아요. 저장한 뒤 그 탭에서 `F5`를 눌러요.
- 다음 날 VS Code를 새로 켜면 미리 보기는 닫혀 있어요. 편집기에서 볼 파일을 연 다음 위 1~2처럼 다시 열어요.
:::

:::info 알아두기
미리 보기 창은 VS Code 안에 들어 있어서 Edge나 Chrome이 아니에요. 그래서 이 창에서 `F12`를 눌러도 브라우저의 개발자 도구는 열리지 않아요. 개발자 도구는 Day 6에서 배워요. 그때 주소를 복사해서 Edge로 여는 방법도 알려 드려요.
:::

### 9단계 · Chrome 설치 (5분)

Edge만 있어도 이 교재를 끝까지 따라갈 수 있어요. 다만 Chrome으로도 같은 화면이 나오는지 확인해 보면 도움이 되고, 많은 사람이 Chrome을 쓰기 때문에 한 번 설치해 둬요. 건너뛰어도 괜찮아요.

**어디서:** 브라우저 주소 표시줄

**무엇을:**

1. `https://www.google.com/chrome/`을 입력하고 `Enter`를 눌러요.
2. **Chrome 다운로드** 버튼을 클릭해요.
3. 내려받은 설치 파일을 실행하고, 설치가 끝날 때까지 기다려요.
4. Chrome이 "기본 브라우저로 설정할까요?"라고 물으면 바꾸지 않아도 돼요.

:::success
시작 버튼(⊞)을 누르고 `chrome`을 입력하면 **Google Chrome**이 보이고, 실행하면 Chrome 창이 열려요. 기본 브라우저 설정을 계속 물어도 무시해도 돼요.
:::

VS Code에서 새 파일 `C:\dev\hello\tools.html`을 만들어요.

힌트: 닫는 태그가 저절로 생겨요. `<h1>`을 입력하면 `</h1>`이 자동으로 따라 나와요. 그 사이에 글을 쓰고 `End` 키로 줄 끝으로 가세요. 자동으로 생긴 것을 못 보고 또 입력했다면 `</h1></h1>`처럼 겹쳐요. 그럴 땐 하나를 지워요. 직접 입력이 어렵다면 정답 코드의 **복사** 버튼으로 붙여 넣어도 돼요.

### 과제 2 · 명령 팔레트로 `favorites.html` 열기 (보통 ⭐⭐, 10분)

마우스로 아이콘을 누르지 않고 키보드만으로 `favorites.html`을 Live Preview에 열어 보세요.

- 탐색기에서 `favorites.html`을 클릭해 탭을 앞으로 가져와요.
- `Ctrl + Shift + P`로 명령 팔레트를 열어요.
- 명령 이름을 쳐서 `Live Preview: Show Preview`를 실행해요.
- 미리 보기 창에 `/favorites.html` 주소로 내용이 보이는지 확인해요.

### 과제 3 · 자동 저장 비교 (도전 ⭐⭐⭐, 5분)

**파일 → 자동 저장**을 껐을 때와 켰을 때, 파일을 고치면 탭의 ●가 어떻게 달라지는지 한 문장으로 적어 보세요. 직접 껐다 켜며 확인해요.

## 🧯 자주 막히는 곳

모든 문제와 드문 경우는 [문제 해결 모음](#/page/troubleshooting)에 있어요.

### 내려받은 VS Code 설치 파일이 안 보여요

**원인:** 브라우저가 파일을 `다운로드` 폴더에 저장하는데, 폴더가 OneDrive 안으로 옮겨져 있거나 내려받기가 끝나지 않았을 수 있어요. 그래서 파일 탐색기에서 찾으면 안 보일 때가 있어요.

**해결:**

1. 브라우저에서 `Ctrl + J`를 눌러 다운로드 목록을 열어요.
2. 목록 맨 위의 `VSCodeUserSetup-…` 항목이 "완료"인지 확인해요. 진행 중이면 끝날 때까지 기다려요.
3. 항목을 클릭하면 바로 실행돼요. 폴더 모양 아이콘(폴더에 표시)을 누르면 파일이 있는 폴더가 열려요.
4. 목록에 아무것도 없으면 `https://code.visualstudio.com/`에서 **Download for Windows** 버튼을 다시 눌러요.
5. 설치 마법사 첫 화면이 열리면 해결된 거예요.

### 파란 "Windows의 PC 보호" 창이나 "이 앱이 디바이스를 변경하도록 허용하시겠어요?" 창이 떠요

**원인:** Windows는 내려받은 실행 파일을 처음 실행할 때 게시자를 확인하라고 알려 줘요. 처음 보는 프로그램이면 파란 경고(Microsoft Defender SmartScreen)가 뜨고, 설치할 때 사용자 계정 컨트롤(UAC) 창이 뜰 수도 있어요. 문구는 Windows 버전에 따라 조금 달라요.

**해결:**

1. 창에 쓰인 앱 이름이 Visual Studio Code인지, 게시자가 **Microsoft Corporation**인지 읽어요. 이 확인 없이 누르지 않는 습관이 중요해요.
2. 파란 경고 창이면 글자 **추가 정보**를 클릭하고, 새로 나타난 **실행** 버튼을 클릭해요. 게시자가 Microsoft가 아니거나 다른 사이트에서 받은 파일이면 실행하지 말고 지워요.
3. 사용자 계정 컨트롤 창이면 게시자를 확인하고 **예**를 클릭해요. User setup은 보통 이 창이 뜨지 않아요.
4. 설치 마법사의 사용권 계약 화면이 열리면 해결된 거예요.

### 설치할 때 관리자 암호를 물어요 (VSCodeSetup 파일을 받았어요)

**원인:** 내려받은 파일 이름이 `VSCodeSetup-…`으로 시작하면 모든 사용자용으로 `Program Files`에 설치하는 System setup이에요. 이 방식은 관리자 권한이 필요해서 관리자 암호를 물어요. 이 교재는 관리자 권한이 필요 없는 User setup(`VSCodeUserSetup-…`)을 써요.

**해결:**

1. 암호를 묻는 창은 닫고, 설치 마법사도 취소해요.
2. 브라우저에서 `https://code.visualstudio.com/`을 열고 **Download for Windows** 버튼 대신 **Other platforms**(다른 플랫폼) 또는 다운로드 페이지의 Windows **User Installer**(x64)를 골라 내려받아요. 화면 이름은 버전에 따라 조금 달라요.
3. 내려받은 파일 이름이 `VSCodeUserSetup-`으로 시작하는지 확인하고 실행해요.
4. 관리자 암호 없이 사용권 계약 화면까지 가면 해결된 거예요.

### 한국어 팩을 설치했는데 메뉴가 영어예요

**원인:** 한국어 팩은 설치한 뒤 VS Code를 다시 시작해야 적용돼요. 오른쪽 아래 알림의 **Change Language and Restart** 버튼을 놓쳤거나 알림이 사라졌을 수 있어요.

**해결:**

1. `Ctrl + Shift + P`를 눌러 명령 팔레트를 열어요.
2. `Configure Display Language`를 입력하고 `Enter`를 눌러요.
3. 언어 목록에서 `한국어`(`ko`)를 클릭해요. 목록에 없으면 확장 화면에서 Korean Language Pack이 설치(Installed)되어 있는지 확인해요.
4. 오른쪽 아래에 나오는 **Restart**(다시 시작) 버튼을 클릭해요.
5. 다시 열린 창의 메뉴가 `파일`, `편집`, `선택 영역`으로 시작하면 해결된 거예요.

### 창 위에 "제한 모드"(Restricted Mode)라고 나와요

**원인:** 폴더를 처음 열 때 나온 신뢰 창에서 **아니요**를 눌렀거나 창을 닫았어요. VS Code는 모르는 폴더의 코드를 함부로 실행하지 않도록 제한 모드로 시작해요. 내가 만든 폴더는 신뢰해도 안전해요.

**해결:**

1. 편집기 맨 위의 제한 모드 안내 줄에서 **관리**(Manage) 버튼을 클릭해요. 안내 줄이 없으면 창 맨 아래 상태 표시줄의 **제한 모드** 글자를 클릭해요.
2. 열린 화면에서 **폴더 신뢰**(Trust Folder) 계열의 버튼을 클릭해요. 문구는 버전에 따라 조금 달라요.
3. 창 위쪽의 "제한 모드" 글자가 사라지면 해결된 거예요.

### 탐색기에 폴더가 없고 파일 하나만 열려요

**원인:** **파일 → 파일 열기**로 `hello.html` 하나만 열었어요. 폴더가 아니라 파일을 연 상태라서 탐색기에 파일 목록이 안 보이고, Live Preview도 이 파일 하나만 다루기 어려워요.

**해결:**

1. 맨 위 메뉴 **파일 → 폴더 열기**를 클릭해요.
2. 주소 표시줄에 `C:\dev\hello`를 입력하고 `Enter`, 이어서 **폴더 선택**을 클릭해요.
3. 저장하지 않은 내용이 있다는 창이 뜨면 먼저 `Ctrl + S`로 저장해요.
4. 탐색기 맨 위에 `HELLO`가 보이고 그 아래에 파일 목록이 있으면 해결된 거예요.
