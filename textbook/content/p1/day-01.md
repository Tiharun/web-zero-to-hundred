## 🎯 오늘의 목표

오늘이 끝나면 이렇게 할 수 있어요.

- 인터넷, 웹, 브라우저, 서버가 무엇이고 서로 어떻게 이어지는지 내 말로 설명할 수 있어요.
- 파일 탐색기에서 파일 확장명이 보이게 켜고, 확장자로 파일 종류를 구별할 수 있어요.
- `C:\dev\hello` 폴더를 만들고, 메모장으로 `hello.html`을 만들어 브라우저로 열 수 있어요.
- "고치기 → 저장(`Ctrl + S`) → 새로 고침(`F5`)"이라는 웹 개발의 기본 순서를 직접 해 볼 수 있어요.

**예상 시간: 90분** (개념 이해 20분 · 따라하기 40분 · 과제 25분 · 정리 5분)

:::tip 이 교재를 읽는 방법
단계마다 **어디서**(앱·메뉴·전체 경로), **무엇을**(누를 것·입력할 것), **결과**(초록색 "이렇게 보이면 성공" 상자)가 적혀 있어요. 성공 상자와 내 화면이 다르면 다음 단계로 넘어가지 말고, 아래 **🧯 자주 막히는 곳**을 먼저 보세요. 모르는 낱말은 밑줄 친 글자를 누르면 [용어 사전](#/page/glossary)으로 가요.
:::

:::path 📂 시작 상태
첫날이라 미리 있어야 할 파일이나 폴더가 없어요. Windows 11 컴퓨터 한 대면 충분하고, 오늘은 인터넷에 연결되어 있지 않아도 돼요.

- `C:\dev` 폴더: 아직 없어요. 오늘 만들어요.
- 설치할 프로그램: 없어요. Windows에 들어 있는 **파일 탐색기**, **메모장**, **Microsoft Edge**만 써요.
:::

## 📖 개념 이해

### 인터넷과 웹은 같은 말이 아니에요

**비유부터 볼게요.** 인터넷은 전 세계 컴퓨터를 잇는 **도로망**이에요. 웹은 그 도로를 따라 배달되는 수많은 **안내 책자**(웹페이지)와, 책자끼리 "다음 책자는 저기 있어요"라고 가리키는 **표지판**(링크)의 모음이에요. 도로 위에는 책자 말고도 택배(이메일), 전화(메신저) 같은 다른 것도 다녀요.

**정확한 정의는 이래요.**

- **[[인터넷]]**(Internet)은 전 세계의 컴퓨터를 서로 연결한 거대한 통신망이에요. 메신저, 온라인 게임, 이메일, 웹이 모두 이 통신망 위에서 움직여요.
- **[[웹]]**(Web)은 인터넷 위에서 웹페이지를 주고받고, 링크(누르면 다른 페이지로 넘어가는 연결)로 서로 이어 주는 서비스예요. 정식 이름은 World Wide Web(WWW)이에요.

### 브라우저와 서버: 주문하고 받아 오는 관계

**비유:** 음식 배달 앱을 떠올려 보세요. 내가 앱에서 가게 주소를 골라 주문하면, 가게가 음식을 만들어 보내고, 나는 받아서 먹어요. 웹에서는 내가 **주소**를 입력하면, 멀리 있는 컴퓨터가 **파일**을 보내 주고, 내 컴퓨터의 프로그램이 그 파일을 **화면**으로 그려 줘요.

**정확한 정의:**

- **[[브라우저]]**(browser)는 웹페이지 파일을 받아 와서 사람이 볼 수 있는 화면으로 그려 주는 프로그램이에요. Windows 11에는 **Microsoft Edge**가 기본으로 들어 있어요. **Google Chrome**도 많이 쓰는데, 같은 웹페이지는 Edge와 Chrome에서 거의 똑같이 보여요. 그래서 이 교재는 둘 중 아무거나 써도 돼요.
- **[[서버]]**(server)는 웹페이지 파일을 보관하고 있다가, 요청이 오면 보내 주는 컴퓨터예요.
- **[[URL]]**(유알엘)은 자료가 있는 위치를 가리키는 주소예요. 브라우저 맨 위 주소 표시줄에 보이는 글자가 URL이에요. `https://`로 시작하면 인터넷 너머의 서버에서, `file:///`로 시작하면 내 컴퓨터 안에서 파일을 가져와요.

주소를 입력한 뒤 화면이 보이기까지는 이런 순서로 일이 일어나요.

```text
① 나: 주소(URL)를 입력해요
   │  "이 페이지 주세요"
   ▼
② 서버: HTML 파일을 보내요
   │  hello.html
   ▼
③ 브라우저: 화면에 그려요
   │
   ▼
④ 나: 웹페이지를 봐요
```

오늘은 ②번 서버 없이, 내 컴퓨터에 있는 파일을 브라우저로 **바로** 열어 볼 거예요. 그래서 주소가 `https://`가 아니라 `file:///`로 시작해요. 내 사이트를 진짜 서버에 올려서 누구나 `https://` 주소로 볼 수 있게 하는 일은 Day 14에 해요.

### 웹페이지, 웹사이트, 그리고 HTML

- **[[웹페이지]]**(web page)는 브라우저 화면 한 장에 보이는 문서 하나예요. 보통 HTML 파일 하나가 웹페이지 하나예요.
- **[[웹사이트]]**(website)는 링크로 서로 이어진 웹페이지 여러 장을 한 주소 아래에 모아 둔 묶음이에요. 앞으로 30일 동안 만들 "나의 크리에이터 홈페이지"가 바로 웹사이트예요.
- **[[HTML]]**(에이치티엠엘)은 웹페이지의 내용과 구조를 적는 언어예요. "여기는 큰 제목, 여기는 문단"처럼 꺾쇠 괄호 `< >`로 감싼 표시를 글자 사이에 넣어서 써요.

HTML처럼 컴퓨터가 알아듣는 규칙에 맞춰 쓴 글을 **[[코드]]**(code)라고 해요. HTML 파일은 이런 코드가 글자로만 담긴 파일이에요. 그래서 **[[텍스트 편집기]]**(text editor)로 만들어요. 텍스트 편집기는 글꼴·색 같은 꾸밈 없이 글자만 쓰고 저장하는 프로그램이고, Windows에 들어 있는 **메모장**이 대표적인 텍스트 편집기예요.

:::warn 워드·한글(HWP)로 만들면 안 돼요
워드나 한글 같은 문서 프로그램은 글자 말고도 글꼴·크기 같은 꾸밈 정보를 파일에 함께 저장해요. 그래서 브라우저가 HTML로 읽을 수 없어요. HTML은 꼭 메모장 같은 텍스트 편집기로 만들어요.
:::

:::info 실무에서는
회사 홈페이지나 쇼핑몰도 출발점은 오늘 만들 파일과 같아요. 결국 HTML 파일과 그림 파일 등을 서버에 올려 둔 거예요. 다른 점은 파일 수가 훨씬 많고, 메모장 대신 코드를 쓰기 편한 전용 편집기를 쓴다는 것이에요. 우리도 내일(Day 2) 그런 편집기인 VS Code를 설치해요.
:::

### 파일, 폴더, 확장자, 경로

**비유:** 서류(파일)를 서류철(폴더)에 넣어 보관하고, 서류 겉에는 "계약서", "영수증" 같은 종류 스티커(확장자)를 붙여 둬요. 그리고 "3층 → 두 번째 캐비닛 → 파란 서류철" 처럼 위치를 적어 두면(경로) 누구든 그 서류를 찾을 수 있어요.

**정확한 정의:**

- **[[파일]]**(file)은 컴퓨터에 이름을 붙여 저장한 자료 한 덩어리예요. 글, 사진, 음악, 프로그램이 모두 파일이에요.
- **[[폴더]]**(folder)는 파일과 다른 폴더를 담아 정리하는 상자예요. 폴더 안에 폴더를 넣을 수 있어요.
- **[[확장자]]**(extension)는 파일 이름에서 **마지막 점(.) 뒤**에 붙은 글자예요. Windows는 확장자를 보고 이 파일을 어떤 앱으로 열지 정해요. Windows 메뉴에서는 "파일 확장명"이라고 불러요.
- **[[경로]]**(path)는 파일이 어디에 있는지 드라이브부터 차례로 적은 주소예요.

자주 보는 확장자는 이런 것들이에요.

| 확장자 | 어떤 파일? | 더블클릭하면 열리는 앱 |
|---|---|---|
| `.txt` | 글자만 있는 텍스트 문서 | 메모장 |
| `.html` | 웹페이지(HTML) | 브라우저(Edge 또는 Chrome) |
| `.png`, `.jpg` | 그림·사진 | 사진 앱 |
| `.exe` | 실행 프로그램 | 프로그램이 바로 실행돼요 |

점이 여러 개 있으면 **마지막 점 뒤만** 확장자예요. 그래서 `hello.html.txt`는 이름이 `hello.html`이고 확장자가 `.txt`인 텍스트 문서예요. 웹페이지가 아니에요. 초보자가 가장 많이 막히는 곳이라 오늘 따라하기에서 꼭 확인해요.

:::warn 확장자를 숨기면 위험해요
Windows는 처음 설치했을 때 확장자를 숨기도록 되어 있어요. 이 상태에서는 `사진.jpg.exe`라는 프로그램이 `사진.jpg`처럼 보여서, 사진인 줄 알고 열었다가 나쁜 프로그램이 실행될 수 있어요. 개발자는 항상 확장자를 보이게 켜 두고 써요.
:::

경로는 이렇게 읽어요. 오늘 만들 파일의 경로예요.

```text
C:\dev\hello\hello.html
│  │   │     └ 파일: hello.html
│  │   └ 폴더: hello
│  └ 폴더: dev
└ 드라이브: C
```

맨 앞 `C:`는 C 드라이브, 그다음 `dev`는 C 드라이브 맨 위의 폴더, `hello`는 `dev` 안의 폴더, 마지막 `hello.html`은 `hello` 안의 파일이에요. 파일 이름 `hello.html`은 이름 `hello`와 확장자 `.html`로 나뉘어요.

Windows는 폴더와 폴더 사이를 `\`(역슬래시)로 구분해요. 한국어 키보드에서는 `Enter` 키 위쪽이나 `Backspace` 키 옆에 있는 `₩` 키를 누르면 `\`가 입력돼요. 글꼴에 따라 화면에 `₩`로 보여도 같은 글자예요.

### 왜 `C:\dev`에 만들까요?

바탕 화면이나 문서 폴더는 실제 경로가 `C:\Users\내이름\OneDrive\문서`처럼 길고, 한글·빈칸이 섞이기 쉬워요. 또 OneDrive가 파일을 자동으로 인터넷에 동기화하면서 파일을 잠그기도 해요. 이런 것들은 나중에 개발 도구를 헷갈리게 만들어요. 그래서 이 교재는 모든 실습을 짧고 영어로만 된 `C:\dev` 폴더 안에서 해요. 폴더와 파일 이름도 **영어 소문자, 빈칸 없이** 짓는 습관을 오늘부터 들여요.

## 🛠️ 따라하기

모두 8단계예요. 한 단계를 끝낼 때마다 성공 상자와 내 화면을 비교해요.

### 1단계 · 파일 탐색기 열기 (2분)

**어디서:** 화면 맨 아래 작업 표시줄

**무엇을:** 노란 폴더 모양 아이콘(**파일 탐색기**)을 클릭해요. 아이콘이 안 보이면 키보드의 Windows 로고 키(⊞)를 누른 채로 `E`를 눌러요. 이 교재는 이렇게 두 키를 함께 누르는 것을 `Win + E`처럼 `+`로 적어요.

:::success
새 창이 열리고, 창 왼쪽에 **홈**, **내 PC** 같은 목록이 보여요. 이 왼쪽 목록을 **탐색 창**이라고 불러요.
:::

### 2단계 · 파일 확장명이 보이게 켜기 (3분)

**어디서:** 파일 탐색기 창 위쪽의 도구 모음

**무엇을:**

1. 도구 모음에서 **보기**를 클릭해요.
2. 펼쳐진 메뉴 아래쪽의 **표시**에 마우스를 올려요.
3. 옆에 나온 목록에서 **파일 확장명**을 클릭해요.

메뉴 이름은 Windows 11 기준이에요(작성 기준일 2026-11). 버전에 따라 이름이 조금 다를 수 있어요. 영어 Windows에서는 **View → Show → File name extensions**예요.

:::success
**보기 → 표시**를 다시 열었을 때 **파일 확장명** 앞에 체크 표시(✓)가 있어요. 이 설정은 한 번 켜면 계속 켜져 있어요.
:::

:::tip 보기 메뉴가 안 보이면
창이 좁으면 도구 모음의 버튼이 오른쪽 끝 **⋯**(더 보기) 안으로 숨어요. 창 오른쪽 위의 □(최대화) 버튼을 눌러 창을 크게 만들면 다시 보여요.
:::

### 3단계 · `C:\dev` 폴더 만들기 (5분)

**어디서:** 파일 탐색기 → 왼쪽 탐색 창의 **내 PC** → **로컬 디스크 (C:)**

**무엇을:**

1. 왼쪽 탐색 창에서 **내 PC**를 클릭해요.
2. 오른쪽에 보이는 **로컬 디스크 (C:)** 아이콘을 더블클릭해요. 컴퓨터에 따라 `Windows (C:)`처럼 이름이 다를 수 있어요. 괄호 안에 `C:`가 있는 것을 고르면 돼요.
3. 도구 모음 맨 왼쪽의 **새로 만들기**(⊕ 모양)를 클릭하고 **폴더**를 클릭해요. 단축키 `Ctrl + Shift + N`을 눌러도 돼요.
4. 새 폴더의 이름 칸이 파랗게 선택된 상태에서 영어로 `dev`를 입력하고 `Enter`를 눌러요.

:::warn 관리자 권한을 묻는 창이 뜨면
이름을 정하는 순간 "Destination Folder Access Denied"(대상 폴더 액세스 거부) 창이 뜨면 **계속**을 누르고, "사용자 계정 컨트롤" 창이 뜨면 **예**를 눌러요. 비밀번호를 묻는데 모른다면 [문제 해결 모음](#/page/troubleshooting)에서 그 이름의 항목을 보세요. 해결한 뒤에는 아래 4단계로 이어가면 돼요.
:::

:::warn 한글이 입력되면
`dev`를 쳤는데 `ㅇㄷㅍ`이 나오면 키보드가 한글 입력 상태예요. `한/영` 키를 한 번 누르고 `Backspace`로 지운 뒤 다시 입력해요. 이미 이름이 정해졌다면 폴더를 클릭하고 `F2`를 눌러 이름을 다시 입력해요.
:::

:::success
`로컬 디스크 (C:)` 안에 `Program Files`, `사용자`(영어 Windows는 `Users`), `Windows` 같은 폴더들과 함께 `dev` 폴더가 보여요.
:::

### 4단계 · `C:\dev` 안에 `hello` 폴더 만들기 (3분)

**어디서:** 파일 탐색기 → `C:\dev`

**무엇을:**

1. 방금 만든 `dev` 폴더를 더블클릭해서 들어가요.
2. 3단계와 같은 방법(**새로 만들기 → 폴더**)으로 `hello` 폴더를 만들어요.
3. `hello` 폴더를 더블클릭해서 들어가요.
4. 창 위쪽의 긴 칸(**주소 표시줄**)에서 글자 오른쪽의 빈 곳을 클릭해요.

:::success
주소 표시줄의 글자가 `C:\dev\hello`로 바뀌어 보여요. 폴더 안은 비어 있다고 나와요. 이 파일 탐색기 창은 닫지 말고 그대로 두세요. 7단계에서 다시 써요.
:::

### 5단계 · 메모장을 열고 `hello.html`로 먼저 저장하기 (7분)

내용을 쓰기 전에 **이름부터** 정확히 붙여서 저장해요. 이름이 잘못 붙는 실수(`hello.html.txt`)를 빈 파일일 때 바로 찾아 고칠 수 있어서예요.

저장할 때 두 가지를 챙겨요. 첫째, 파일 이름을 **따옴표로 감싸요**. 메모장은 파일 형식이 텍스트 문서로 되어 있으면 이름 끝에 `.txt`를 몰래 붙일 수 있어요. 이름을 따옴표로 감싸면 Windows가 "이 이름 그대로 저장해 주세요"라는 뜻으로 알아듣고 아무것도 붙이지 않아요. 둘째, **인코딩**을 확인해요. 인코딩은 글자를 파일에 저장하는 방식인데, 한글이 깨지지 않으려면 **[[UTF-8]]**(유티에프 에이트)이어야 해요. UTF-8은 전 세계 글자를 모두 담을 수 있는 저장 방식이에요.

**어디서:** 작업 표시줄의 **시작** 버튼(⊞) → 검색 → **메모장**

**무엇을:**

1. **시작** 버튼을 누르고 `메모장`(한글 입력 상태) 또는 `notepad`(영어 입력 상태)를 입력한 뒤 `Enter`를 눌러요. 메모장 창이 열려요. 전에 쓰던 글이 보이면 `Ctrl + N`을 눌러 빈 새 탭을 열어요(메모장은 지난번에 열어 둔 탭을 다시 보여 주기도 해요).
2. 메모장 왼쪽 위의 **파일** 메뉴를 누르고 **다른 이름으로 저장**을 클릭해요(영어 Windows: **File → Save as**). 단축키는 `Ctrl + Shift + S`예요.
3. 저장 창이 열리면 창 위쪽 주소 표시줄의 빈 곳을 클릭하고, `C:\dev\hello`를 입력한 뒤 `Enter`를 눌러요.
4. 창 아래쪽 **파일 형식** 칸을 눌러 **모든 파일** `(*.*)` 항목을 골라요(영어 Windows: **Save as type → All files**). 목록에 없으면 그대로 둬도 괜찮아요. 다음 줄의 따옴표가 지켜 줘요.
5. **파일 이름** 칸의 글자를 모두 지우고, 따옴표까지 그대로 `"hello.html"`을 입력해요. 따옴표(`"`)는 `Shift` 키를 누른 채 `Enter` 키 왼쪽의 `'` 키를 누르면 입력돼요.
6. **인코딩** 칸이 보이면 **UTF-8**로 되어 있는지 확인해요. 처음부터 UTF-8이면 그대로 둬요.
7. **저장**을 클릭해요.

:::success
- 메모장 위쪽 탭(또는 제목 줄)에 `hello.html`이 보여요.
- 파일 탐색기의 `C:\dev\hello` 창에 `hello.html` 파일이 생겼어요. 이름이 `hello.html`로 끝나고(뒤에 `.txt`가 붙어 있지 않아요), 아이콘이 브라우저(Edge 또는 Chrome) 모양이에요.
:::

:::warn hello.html.txt가 보이거나 hello.html이 안 보이면
여기서 멈추고 메모장에서 다시 저장해요. 빈 파일이라 지금 고치는 게 가장 쉬워요. 이름이 잘못 붙었을 때(`hello.html.txt`)도, 다른 폴더(문서·OneDrive 등)에 저장됐을 때도 방법은 같아요.

1. 메모장으로 돌아가서 **파일 → 다른 이름으로 저장**을 클릭해요.
2. 저장 창의 주소 표시줄 빈 곳을 클릭하고 `C:\dev\hello`를 입력한 뒤 `Enter`를 눌러요.
3. **파일 형식**은 **모든 파일** `(*.*)`, **파일 이름**은 따옴표까지 `"hello.html"`로 입력하고 **저장**을 클릭해요.
4. 메모장 탭 이름이 `hello.html`로 바뀌었는지 확인해요.
5. 파일 탐색기 `C:\dev\hello`에 `hello.html`이 보이는지 확인해요. 잘못 만든 `hello.html.txt`가 같이 있으면 한 번 클릭하고 `Delete` 키를 눌러 지워요(휴지통으로 가요). 다른 폴더에 잘못 저장된 파일은 그대로 둬도 괜찮아요.
:::

### 6단계 · 첫 HTML 코드를 입력하고 저장하기 (10분)

**어디서:** 메모장(탭 이름이 `hello.html`인 창)

**무엇을:** 아래 코드를 메모장에 그대로 입력해요. 직접 타이핑하면 손에 가장 잘 익어요. 오타가 걱정되면 코드 상자 오른쪽 위의 **복사** 버튼을 누르고 메모장을 클릭한 뒤 `Ctrl + V`로 붙여 넣어도 돼요. 다 입력했으면 `Ctrl + S`를 눌러 저장해요.

📄 C:\dev\hello\hello.html
```html
<!DOCTYPE html>
<html lang="ko">
<head>
<meta charset="utf-8">
<title>나의 첫 웹페이지</title>
</head>
<body>
<h1>안녕하세요!</h1>
<p>제가 처음으로 만든 웹페이지예요.</p>
</body>
</html>
```

직접 타이핑할 때 헷갈리는 글자는 이렇게 입력해요. 기호와 영어는 영어 입력 상태(작업 표시줄 오른쪽 아래가 **A**)에서 치고, 한글 글자(제목·문장)를 칠 때만 `한/영` 키로 바꿔요. 한글을 다 쳤으면 `한/영` 키를 한 번 더 눌러 영어(**A**)로 되돌린 뒤 이어서 입력해요.

| 글자 | 누르는 키 |
|---|---|
| `<` | `Shift` + 쉼표(`,`) 키 |
| `>` | `Shift` + 마침표(`.`) 키 |
| `/` | 오른쪽 `Shift` 옆의 `/` 키 |
| `!` | `Shift` + `1` |
| `"` | `Shift` + `'` 키 (`Enter` 왼쪽) |

각 줄의 뜻은 지금은 이 정도만 알면 돼요. 한 줄씩 자세한 규칙은 Day 3에서 배워요.

- `<!DOCTYPE html>`: "이 파일은 HTML 문서예요"라는 첫 줄이에요.
- `<html lang="ko">` ~ `</html>`: 문서 전체를 감싸요. `ko`는 한국어라는 뜻이에요.
- `<head>` ~ `</head>`: 화면에는 안 보이는 설정을 적는 칸이에요.
- `<meta charset="utf-8">`: "이 파일은 UTF-8로 저장했어요"라는 표시예요. 한글이 깨지지 않게 해 줘요.
- `<title>` ~ `</title>`: 브라우저 **탭**에 보이는 제목이에요.
- `<body>` ~ `</body>`: 화면에 보이는 내용을 적는 칸이에요.
- `<h1>` ~ `</h1>`: 큰 제목이에요.
- `<p>` ~ `</p>`: 문단(보통 글)이에요.

`<p>`로 열고 `</p>`로 닫는 것처럼, 앞에 `/`가 붙은 쪽이 "여기까지"를 뜻하는 닫는 표시예요.

:::success
메모장 탭의 파일 이름 옆에 있던 동그라미(●)나 별표(\*)가 사라졌어요. 저장이 끝났다는 뜻이에요.
:::

### 7단계 · 브라우저로 열기 (5분)

**어디서:** 파일 탐색기 → `C:\dev\hello`

**무엇을:** `hello.html` 파일을 더블클릭해요.

- 교재를 보고 있던 브라우저 창에 새 탭으로 열릴 수 있어요. 교재 탭은 그대로 있으니 위쪽 탭을 눌러 오가면 돼요.
- Edge를 처음 여는 컴퓨터라면 시작 설정 화면이 먼저 나올 수 있어요. 로그인하지 않아도 돼요. 화면 안내에 따라 넘기거나 닫으면 내 파일이 열려요.
- 어떤 앱으로 열지 묻는 창이 뜨면 **Microsoft Edge**(또는 Google Chrome)를 고르고 **항상**을 눌러요(창의 문구는 버전에 따라 조금 달라요).
- Chrome으로 보고 싶다면 `hello.html`을 오른쪽 클릭하고 **연결 프로그램 → Google Chrome**을 골라요. Chrome이 아직 없다면 Edge로 충분해요. Chrome 설치는 Day 2에 해요.

:::success
- 브라우저 탭에 **나의 첫 웹페이지**가 보여요.
- 화면에 큰 글씨의 제목 **안녕하세요!** 와, 그 아래 보통 글씨의 문장 "제가 처음으로 만든 웹페이지예요."가 보여요.
- 주소 표시줄에 `C:/dev/hello/hello.html`이 들어간 주소가 보여요. 앞에 `file:///`나 `파일`이라는 글자가 붙어 보일 수 있어요. 둘 다 "내 컴퓨터의 파일"이라는 뜻이에요.
:::

화면에 `<h1>` 같은 꺾쇠 표시가 그대로 보이거나 한글이 깨져 보이면 아래 🧯 자주 막히는 곳을 보세요.

이제 `hello.html`은 더블클릭하면 브라우저로 열려요. 내용을 고칠 때는 메모장으로 열어야 해요. 지금은 메모장이 열려 있으니 그대로 8단계로 가면 돼요.

:::tip 메모장으로 다시 여는 법
메모장을 닫았다면 이렇게 다시 열어요.

- 파일 탐색기 `C:\dev\hello`에서 `hello.html`을 오른쪽 클릭하고 **연결 프로그램 → 메모장**을 골라요.
- 목록에 메모장이 없으면 **다른 앱 선택**에서 메모장을 고르고 **한 번만**을 눌러요. **항상**을 누르면 더블클릭할 때도 메모장이 열려 버려요. 이미 **항상**을 눌렀다면 `hello.html`을 오른쪽 클릭하고 **연결 프로그램 → 다른 앱 선택**에서 **Microsoft Edge**(또는 Chrome)를 골라 **항상**을 눌러 되돌려요.
- 다른 방법: 메모장에서 **파일 → 열기**를 누르고, 오른쪽 아래 형식 칸을 **모든 파일** `(*.*)`로 바꾼 뒤 `C:\dev\hello\hello.html`을 골라요.
:::

### 8단계 · 고치고 → 저장하고 → 새로 고침 (5분)

**어디서:** 메모장(`hello.html`)과 브라우저를 번갈아 써요. 작업 표시줄에서 각 앱 아이콘을 누르면 앞으로 나와요.

**무엇을:**

1. 메모장에서 `<h1>안녕하세요!</h1>` 줄을 `<h1>안녕하세요, 저는 달빛곰이에요!</h1>`처럼 바꿔요. 달빛곰 자리에는 내 닉네임을 써요.
2. `Ctrl + S`를 눌러 저장해요.
3. 브라우저를 클릭하고 `F5`를 눌러요. 주소 표시줄 왼쪽의 ↻(새로 고침) 버튼을 눌러도 같아요.

:::success
큰 제목이 방금 바꾼 문장으로 보여요. 이 "고치기 → 저장(`Ctrl + S`) → 새로 고침(`F5`)" 순서가 앞으로 매일 쓰는 웹 개발의 기본 동작이에요.
:::

:::tip 노트북에서 F5가 안 먹으면
노트북은 `F5` 키에 화면 밝기 같은 다른 기능이 먼저 들어 있기도 해요. 그럴 땐 `Fn` 키를 누른 채 `F5`를 누르거나, 주소 표시줄 왼쪽의 ↻ 버튼을 눌러요.
:::

## ✅ 정답

:::answer 과제 1 정답 · 자기소개 페이지
닉네임이 "달빛곰"인 예시예요. 글 내용은 사람마다 달라도 정답이에요. 탭 제목 1개, 큰 제목 1개, 문단 3개가 있고 브라우저에서 그대로 보이면 돼요.

📄 C:\dev\hello\hello.html
```html
<!DOCTYPE html>
<html lang="ko">
<head>
<meta charset="utf-8">
<title>달빛곰의 자기소개</title>
</head>
<body>
<h1>달빛곰</h1>
<p>저는 밤에 하는 게임 방송과 잔잔한 음악을 좋아해요.</p>
<p>시청자와 함께 게임하는 참여형 방송을 하고 싶어요.</p>
<p>이 교재로 방송 일정과 영상을 모아 둔 내 홈페이지를 만들고 싶어요.</p>
</body>
</html>
```

**왜 이렇게 하나요?**

- 탭 제목은 `<head>` 안의 `<title>`이 정해요. 그래서 탭 글자를 바꾸려면 `<title>` 줄을 고쳐요.
- 화면에 보일 글은 모두 `<body>` ~ `</body>` 사이에 써요. `<head>`는 탭 제목 같은 설정을 적는 칸이라서 글을 쓰는 곳이 아니에요.
- 문단마다 `<p>` ~ `</p>`로 따로 감싸야 줄이 나뉘어 보여요. 메모장에서 `Enter`로 줄만 바꾸면 브라우저는 그 줄바꿈을 무시하고 한 줄로 이어 붙여요. 이 규칙은 Day 3에서 다시 다뤄요.
:::

```html
<!DOCTYPE html>
<html lang="ko">
<head>
<meta charset="utf-8">

</head>
<body>
<h1>내가 좋아하는 것 3가지</h1>

<p>방송: 밤에 하는 노래 방송</p>
<p>음식: 떡볶이</p>
</body>
```

**질문의 답:** `favorites.html`의 확장자는 `.html`이에요. 더블클릭하면 브라우저(Edge 또는 Chrome)가 열려요. Windows가 마지막 점 뒤의 확장자 `.html`을 보고 "웹페이지니까 브라우저로 연다"고 정하기 때문이에요.

**왜 이렇게 하나요?** 새 파일을 만들 때마다 5단계처럼 이름을 `"favorites.html"`로 따옴표로 감싸 저장하고, 파일 탐색기에서 확장자를 눈으로 확인하는 습관이 중요해요. 이 습관이 있으면 `.txt`가 붙는 실수를 바로 찾아요.
:::

:::answer 오늘 끝 상태 전체 코드
오늘 따라하기와 과제를 모두 끝내면 아래 상태가 돼요. 중간에 막혔다면 이 폴더와 파일을 그대로 만들고 아래 코드를 붙여 넣어 저장하세요. 그러면 Day 2를 바로 시작할 수 있어요. 글 내용(닉네임·좋아하는 것)은 내 것으로 바꿔도 돼요.


## 🧯 자주 막히는 곳

여기에 없는 증상은 [문제 해결 모음](#/page/troubleshooting)에서 찾아보세요.

### 파일 이름이 hello.html.txt로 저장돼요 (더블클릭하면 메모장이 열려요)

**원인:** 저장할 때 **파일 형식**이 텍스트 문서로 되어 있어서 메모장이 이름 끝에 `.txt`를 붙였어요. 마지막 점 뒤가 확장자라서 이 파일의 진짜 확장자는 `.txt`예요.

**해결(메모장이 열려 있을 때, 가장 안전한 방법):** 메모장에서 다시 저장해요. 파일 탐색기에서 이름만 바꾸면, 열려 있는 메모장은 여전히 옛 이름(`hello.html.txt`)을 기억하고 있어서 다음에 `Ctrl + S`를 누를 때 `hello.html.txt`가 다시 생겨요.

1. 메모장에서 **파일 → 다른 이름으로 저장**을 클릭해요.
2. 주소 표시줄 빈 곳을 클릭하고 `C:\dev\hello`를 입력한 뒤 `Enter`를 눌러요.
3. **파일 형식**은 **모든 파일** `(*.*)`, **파일 이름**은 따옴표까지 `"hello.html"`로 입력하고 **저장**을 클릭해요.
4. 메모장 탭 이름이 `hello.html`인지 확인해요.
5. 파일 탐색기 `C:\dev\hello`에서 남은 `hello.html.txt`를 한 번 클릭하고 `Delete` 키를 눌러 지워요. 오른쪽 클릭 메뉴의 휴지통 모양 아이콘(삭제)을 눌러도 돼요.

**해결(메모장에 열려 있지 않은 파일일 때):** 파일 탐색기에서 이름을 바꿔도 돼요.

1. 파일 탐색기에서 **보기 → 표시 → 파일 확장명**이 체크되어 있는지 확인해요.
2. `hello.html.txt`를 한 번 클릭하고 `F2`를 눌러요(노트북은 `Fn + F2`일 수 있어요). 오른쪽 클릭 메뉴의 **이름 바꾸기**를 눌러도 돼요.
3. 이름의 앞부분(`hello.html`)만 파랗게 선택돼요. 이 상태에서 글자를 치면 파랗게 선택된 `hello.html` 부분이 그 글자로 바뀌니 조심해요. `End` 키를 눌러 커서를 맨 끝으로 옮긴 뒤 `Backspace`를 4번 눌러 `.txt`를 지우고 `Enter`를 눌러요(노트북에서 `End`는 `Fn + →`일 수 있어요). 다른 방법: `Ctrl + A`로 이름 전체를 선택하고 `hello.html`을 새로 입력해요.
4. 아래 경고 창이 뜨면 **예**를 눌러요.

```text
확장명을 변경하면 파일을
사용할 수 없게 될 수도 있습니다.
변경하시겠습니까?
```

영어 Windows에서는 "If you change a file name extension, the file might become unusable. Are you sure you want to change it?"라고 나와요. "확장자를 바꾸면 여는 앱이 달라지는데 정말 바꿀까요?"라는 확인 질문이에요. HTML은 글자로만 된 파일이라 바꿔도 안전해요(문구는 버전에 따라 조금 다를 수 있어요).

메모장에 열어 둔 채로 이름을 이미 바꿨다면, 메모장에서 위의 "메모장이 열려 있을 때" 1~4를 한 번 더 해요. 그리고 5번처럼 파일 탐색기에서 남은 `hello.html.txt`가 있으면 지워요. 바꿀지 묻는 창이 뜨면 **예**를 눌러요.

### `C:\dev\hello`에 `hello.html`이 안 보여요 (다른 폴더에 저장됐어요)

**원인:** 저장 창이 `C:\dev\hello`가 아닌 곳(문서, OneDrive, 바탕 화면 등)을 가리킨 채로 저장했어요. 메모장의 저장 창은 지난번에 저장한 폴더를 먼저 보여 줘요.

**해결:**

1. 메모장으로 돌아가서 **파일 → 다른 이름으로 저장**을 클릭해요.
2. 저장 창 위쪽 주소 표시줄의 빈 곳을 클릭하고 `C:\dev\hello`를 입력한 뒤 `Enter`를 눌러요. 주소 표시줄에 `C:\dev\hello`가 보이는지 확인해요.
3. **파일 형식**은 **모든 파일** `(*.*)`, **파일 이름**은 따옴표까지 `"hello.html"`로 입력하고 **저장**을 클릭해요.
4. 파일 탐색기 `C:\dev\hello` 창에 `hello.html`이 보이면 해결이에요. 다른 폴더에 먼저 저장된 파일은 그대로 둬도 괜찮아요.

### 메모장으로 다시 열고 싶어요 (더블클릭하면 브라우저가 열려요)

**원인:** `.html` 파일은 더블클릭하면 브라우저로 열리게 되어 있어요. 고치려면 메모장으로 골라서 열어야 해요.

**해결:**

1. 파일 탐색기 `C:\dev\hello`에서 `hello.html`을 오른쪽 클릭하고 **연결 프로그램 → 메모장**을 골라요.
2. 목록에 메모장이 없으면 **다른 앱 선택**에서 메모장을 고르고 **한 번만**을 눌러요.
3. 다른 방법: 메모장에서 **파일 → 열기**를 누르고, 오른쪽 아래 형식 칸을 **모든 파일** `(*.*)`로 바꾼 뒤 `C:\dev\hello\hello.html`을 골라 **열기**를 눌러요.
4. 메모장 탭 이름이 `hello.html`이고 내가 쓴 코드가 보이면 성공이에요.

### 한글이 �ȳ��ϼ��� 처럼 깨져 보여요

**원인:** 파일을 UTF-8이 아닌 다른 방식(예: ANSI)으로 저장했어요. HTML 안에는 `<meta charset="utf-8">`이라고 적혀 있어서, 브라우저가 UTF-8로 읽으려다 실패한 거예요.

**해결:** 메모장에서 **파일 → 다른 이름으로 저장**을 누르고(메모장을 닫았다면 "메모장으로 다시 열고 싶어요" 항목대로 먼저 열어요), **인코딩**을 **UTF-8**로 고른 뒤 파일 이름 `"hello.html"`로 같은 곳에 다시 저장해요. 바꿀지 묻는 창에는 **예**를 누르고, 브라우저에서 `F5`를 눌러요.

### 고쳤는데 브라우저 화면이 그대로예요

**원인:** 저장을 안 했거나(메모장 탭 이름 옆에 ● 또는 \*가 있어요), 브라우저를 새로 고치지 않았어요. 브라우저는 파일이 바뀌어도 스스로 다시 읽지 않아요.

**해결:** 메모장에서 `Ctrl + S`, 브라우저에서 `F5`를 차례로 눌러요. 그래도 그대로라면 메모장 탭의 파일 이름과 브라우저 주소가 같은 파일(`C:\dev\hello\hello.html`)인지 확인해요. 메모장 탭 이름이 `hello.html.txt`라면 "파일 이름이 hello.html.txt로 저장돼요" 항목의 "메모장이 열려 있을 때" 방법대로 다시 저장해요.

### 영어를 쳤는데 ㅗ싀 처럼 한글이 입력돼요

**원인:** 한글 입력 상태예요. 한글 상태에서 `html`을 치면 `ㅗ싀`가 돼요.

**해결:** `한/영` 키를 한 번 눌러 작업 표시줄 오른쪽 아래의 **가**가 **A**로 바뀐 것을 확인하고, 잘못 친 글자를 지운 뒤 다시 입력해요.
